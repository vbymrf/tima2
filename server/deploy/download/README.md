# Каталог раздачи пакетов (обновление приложения)

Сюда кладутся собранные пакеты клиента: **APK для Android и MSI для ПК**. Caddy раздаёт их
по `https://api.DOMAIN/download/<имя>` (см. `deploy/caddy/Caddyfile`), а приложение
скачивает по ссылке из `.env`. Сами файлы git не отслеживает.

Порядок выпуска целиком — [ПЛАН-ОБНОВЛЕНИЯ.md §О6](../../../doc_mig/ПЛАН-ОБНОВЛЕНИЯ.md).

## Выпуск новой версии

1. На машине сборки: `release.ps1` в корне репозитория. Он поднимает `tima.versionCode` и
   `tima.versionName` в `client/gradle.properties`, собирает APK и MSI, считает `sha256` и
   размеры и печатает готовые строки для `.env`.
2. Скопировать оба файла сюда **с номером сборки в имени**: `TIMA-7.apk`, `TIMA-7.msi`.
   Общее имя — это ошибка, из-за которой однажды раздаётся вчерашний файл; по экрану
   приложения этого не видно.
3. Вписать напечатанные строки в `deploy/.env`.
4. `docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env up -d backend`.
5. Записать выпуск в `doc_mig/ВЕРСИИ/КЛИЕНТЫ.md`.

## Что означают переменные

| Переменная | Про что |
|---|---|
| `APP_STREAM` | ряд сборок (`v2`). Общий для обеих платформ. **Без него клиент предложение пропустит** |
| `APP_LATEST_VERSION_CODE` / `_NAME` | номер и имя сборки для Android |
| `APP_APK_URL`, `APP_APK_SHA256`, `APP_APK_SIZE` | где APK, его хэш и размер |
| `APP_WIN_VERSION_CODE` / `_NAME` | то же для ПК: номера могут расходиться, платформы выпускаются порознь |
| `APP_MSI_URL`, `APP_MSI_SHA256`, `APP_MSI_SIZE` | где MSI, его хэш и размер |
| `APP_MIN_CLIENT`, `APP_WIN_MIN_CLIENT` | порог: клиент старше него работать не будет. 0 — порога нет |

**`APP_MSI_SHA256` обязателен по смыслу.** У пакета для ПК нет подписи кода (решение
заказчика 2026-09-06 — сертификат не покупается), и хэш остаётся единственной проверкой
скачанного. Без него клиент честно откажется ставить и скажет об этом.

**Каждая переменная обязана быть перечислена в `environment` сервиса `backend`** в
`docker-compose.prod.yml`. Ровно на этом однажды потерялся `APP_STREAM`: он стоял в `.env`,
но до бэкенда не доехал, и вкладка «Обновление» молчала так, будто сломан клиент
(`ВЕРСИИ/СТЕНД.md`, выкатка 2026-08-26).

**Порог поднимают решением, а не по привычке.** `APP_MIN_CLIENT` останавливает работу у
всех, кто не обновился; откат сервера при этом порог снимает — клиент читает отсутствие
поля как «гейта нет», иначе откат выключал бы приложения у всех разом.

Старые версии можно оставлять в каталоге — они не мешают.
