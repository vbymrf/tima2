@@ Строка ввода
Строка внизу переписки — **быстрая отправка**: набрали и нажали «отправить». Оформить текст можно прямо здесь — знаками md (вкладка «Знаки md»).

[[shot help-input]]

- Слева — кнопка **редактора**: зелёная, когда сообщение собрано в нём.
- В строке — эмоджи, галерея и скрепка; набран хоть один знак — остаётся только эмоджи.
- Справа — «отправить»; пока строка пустая — микрофон для голосового.

@@ Знаки md — серым
Знаки остаются в тексте: их можно стереть, поправить, дописать. Серым показан сам знак, а текст между знаками — тем стилем, который увидит получатель.

[[shot help-input]]

По «отправить» знаки, задавшие оформление, уходят — у получателя только стиль:

[[shot help-result]]

Незакрытый знак (`**слово`) и знак у пробела (`a ** b`) остаются текстом.

@@ Ответ через @Ник
В группе `@Ник` в тексте — ответ на последнее сообщение этого человека. Ответить на выбранное — «Ответить» в меню сообщения.

@@ Эмоджи
Эмоджи открывает набор вместо клавиатуры. Строка пустая — эмоджи уходит отдельным сообщением; есть текст — встаёт на место курсора.

@@ Скрепка
Плитки: Файл, Документ, Картинка, Камера, Аудио, Видео, Контакты, Карта, Ссылка. Каждое уходит **отдельным сообщением**.

Раздел **«Из облака»** — Файл, Видео, Музыка: ссылка и название (пусто — имя файла из ссылки). Видео и звук, которые играют в TIMA, приходят виджетом «Видео» или «Аудио», остальное — файлом в облаке.

В группе файлы — только ссылкой: «Файл», «Документ», «Аудио», «Видео» там заменяет раздел «Из облака».

@@ Голосовое
Пока строка пустая, справа — микрофон: нажали — идёт запись. Красная кнопка — стоп, запись можно прослушать; «отправить» — уходит.
