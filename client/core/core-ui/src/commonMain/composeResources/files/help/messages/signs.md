@@ Таблица знаков
Знаки md работают **в строке быстрой отправки**. В поле они видны серым, у получателя — только стиль. В редакторе знаков нет — там оформление кнопками.

| Набрать | Получится |
| --- | --- |
| `# Текст` в начале строки | заголовок 1 — только эта строка |
| `## Текст` | заголовок 2 |
| `### Текст` | заголовок 3 |
| `- пункт` | пункт списка; с отступом 2 и 4 пробела — вложенный, до трёх ступеней |
| `--> текст` | цитата |
| `---` или `***` отдельной строкой | разделитель |
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `++подчёркнутый++` | ++подчёркнутый++ |
| `==маркер==` | ==маркер== |
| `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| \`код\` | `код` |
| `#тег` без пробела | хештег |
| `@Ник` | упоминание; в группе — ответ на последнее сообщение человека |
| адрес `https://…` или `www.…` | под абзацем кнопка «Перейти · домен» |
| незакрытое `**слово` | остаётся текстом |

@@ Блок кода и таблица
**Блок кода** — строка из трёх обратных апострофов (\`\`\`), под ней текст, ниже снова такая строка. Внутри блока знаки не работают:

```
**это не жирный** — код как есть
```

**Таблица** — строки через вертикальную черту, вторая строка — из дефисов. Двоеточие у дефисов — выравнивание: слева, справа, по середине. `^^` в ячейке — слить с ячейкой сверху, `<<` — с ячейкой слева.

@@ Знак как текст
Обратная косая перед знаком — знак остаётся знаком: `\*\*` даёт две звёздочки, а не жирный. Так можно со звёздочкой, плюсом, равно, тильдой, обратным апострофом, решёткой, дефисом, подчёркиванием, вертикальной чертой и знаками `< ^ > @`.
