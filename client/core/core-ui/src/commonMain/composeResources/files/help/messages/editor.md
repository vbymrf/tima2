@@ Как открыть и отправить
Кнопка слева от строки ввода открывает **редактор** — для сообщения со сложным оформлением: заголовки, списки, ряды, виджеты. Набранное в строке со знаками md переезжает в редактор уже оформленным.

- «➤» — отправить; красная — есть ошибки, их список под сообщением.
- «‹» — назад: собранное остаётся черновиком, в строке ввода — «Оформлено в редакторе».

@@ Ленты
Сверху — пять лент:

| Лента | Что в ней |
| --- | --- |
| Текст | Абзац ▾, Жирный, Курсив, Подчёрк., Зачёрк., Маркер, Код, Символ |
| Вставка | Виджет, Картинка, Ссылка, Эмоджи, Подборка, Подкладка, Облако, Карта, Контакт, Ответ, С оформл. |
| Разметка | Выше, Ниже, Ряд, Убрать, ±Столбец, ±Строка, С левой, С верхней, Разъедин. |
| Стиль | Вид, Свойства, Фон, Цвет, Размер, Выровн., Отступ, Раздел., Сброс, JSON |
| Уровень | кому видно сообщение |

@@ Оформление текста
В редакторе **знаков md нет**: набранный знак — просто буква. Оформление — кнопками:

- выделили слово — «Жирный», «Курсив» и другие; без выделения кнопка ждёт следующей буквы;
- «Абзац ▾» — вид строки: заголовок, цитата, список, код.

«Стиль» меняет фон, цвет, размер и выравнивание блока под курсором.

@@ Ряды
«Разметка → Ряд» — строки и столбцы (до 20 строк и 7 столбцов). В ячейку можно писать и класть виджеты. «С левой», «С верхней» — слить ячейки, «Разъедин.» — разделить.

@@ Списки
«Абзац ▾ → Список» — пункт; Enter — следующий пункт, Enter в пустом пункте — конец списка. Вложенность — ступенями списка в «Абзаце ▾». В «Свойствах» списка — «Развернуть по умолчанию» и «Без отступа».

@@ Свойства и вид
«Стиль → Свойства» — что можно изменить у выбранного: вид и название ссылки, строки подборки, «Редактировать метки» у видео и аудио. «Стиль → Вид» — сообщение так, как его увидит получатель.

@@ Черновик и корзина
Черновик сохраняется сам — на устройстве и зашифрованным. Корзина в строке ввода сбрасывает собранное; 5 секунд — «Вернуть».
