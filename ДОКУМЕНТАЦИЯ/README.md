# Документация TIMA

Документация для людей: как система устроена с точки зрения того, кто ей пользуется,
кто её эксплуатирует и кто отвечает за данные. Пишется человеческим языком, без
отсылок к именам файлов и функций.

## Чем это отличается от `doc/`

| | `doc/` | `ДОКУМЕНТАЦИЯ/` |
|---|---|---|
| Для кого | разработчик | пользователь, оператор, юрист |
| Что описывает | как устроен код и протоколы | что происходит с данными и почему |
| Статус | каноника, на неё ссылается код | производная: объясняет принятые решения |
| Язык | технический | обычный |

Правило: если утверждение здесь расходится с `doc/`, прав `doc/` — а расхождение
считается ошибкой этой папки и подлежит исправлению.
