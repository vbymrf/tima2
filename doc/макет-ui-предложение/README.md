# Макет UI — предложение

Пример того, как может выглядеть новое приложение: семь окон из ТЗ и главные
подокна, в одном графическом стиле. Открывается в браузере:

```
doc/макет-ui-предложение/индекс.html
```

## Что это и чем отличается от соседних разделов

| Раздел | О чём |
|---|---|
| [doc_UI](../doc_UI/00-index.md) | ТЗ: что должно быть, окно за окном |
| [макет-ui](../макет-ui/README.md) | опись: что собрано сейчас |
| **макет-ui-предложение** | **как это может выглядеть — предложение по стилю** |

Первое — требования, второе — факт, третье — вариант. Из трёх только второе
описывает действительность.

## Здесь нарочно мало подробностей

Только базовые окна и главные подокна. Ни состояний загрузки, ни пустых
списков, ни разбора условий появления элементов — всё это имеет смысл, когда
стиль уже выбран, а не пока его обсуждают.

Содержимое на макетах выдуманное. Функционал взят из ТЗ и в этом разделе не
обсуждается: вопрос один — как это выглядит.

## Стиль: три решения, из которых выведено остальное

**Бумага, а не панель.** Тёплый почти-белый фон, белые листы, волосяные линии
вместо теней. Переписку читают часами, и контраст должен быть достаточным, но не
звенящим.

**Один акцент.** Глубокий зелёно-синий — и больше ничего цветного, кроме эмоций
и опасных действий. Цвет — дефицитный ресурс: когда его много, он перестаёт
что-либо значить. Сегодняшнее приложение — ровно этот случай: списки чатов,
групп, каналов и аудио-чатов там залиты одним и тем же фиолетовым, и по цвету
ничего не различить.

**Погружение — тёмное.** Слайды, звонок, просмотр фото уходят в тёмную среду:
там главное содержимое, а не оболочка. Остальные окна светлые: длинные тексты
новостной ленты на тёмном читать хуже.

Из этих трёх следует форма: скруглений мало (10 px), кнопки не пилюли, аватары —
квадраты со скруглением, потому что у групп и каналов там логотип, а не лицо, и
круг его режет.

Все значения в [стиль.css](стиль.css) сверху файла — это и есть то, что правят.

## Что взято из ТЗ как данность

- **Переключение окон — по логотипу слева сверху.** Нижней панели вкладок нет
  нигде: логотип открывает [переключение окон](подокна/переключение-окон.html).
- **Зоны телефона:** верхняя панель 52 px, строка ввода 56 px, гроздь кнопок
  плавает в правом нижнем углу.
- **Окно переходов** — универсальное, открывается по имени или аватару где угодно.
- **Шкала эмоций** — восемь состояний четырьмя парами плюс покой.

Макеты нарисованы для телефона. Правила для планшета и десктопа в ТЗ есть
(колонки, перенос грозди кнопок в тулбар), и на стиль они не влияют.

## Уровень видно по ссылке

То же соглашение, что в [макет-ui](../макет-ui/README.md):

```
окна/*.html       — базовое окно
подокна/*.html    — открывается поверх окон, из многих мест
```

Здесь подокна лежат отдельной папкой, а не внутри родителя: окно переходов,
комментарии и оценка вызываются из четырёх-пяти разных окон, и приписать их к
одному нельзя.
