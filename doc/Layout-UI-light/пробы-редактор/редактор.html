Пробы: редактор сообщения

Окно, которое полностью закрывает переписку. Сверху — кнопки редактора, ниже — сообщение таким, каким его увидит собеседник. Быстрых знаков здесь нет: видно уже готовое оформление. Сложное оформление — блочная разметка (JSON): свойства блока целиком и положение вложений. Соседние страницы: строка ввода · Эмоджи, Галерея, Скрепка, Голос.

Два способа оформить — и они не смешиваются (заказчик 2026-10-17):
  • Быстрое оформление (знаки, §6.2) — единственный способ выделить часть одного узла: слово, фразу. Цветов и размеров не задаёт — всё по умолчанию из темы.
  • Блочная разметка (редактор) — свойства всего блока: фон, цвет и размер текста, разделитель, положение вложения. Правки отдельного символа в ней нет. Один блок — один элемент массива узлов.
  • Свойства добавляются поверх умолчания: не указано — значит по умолчанию. Защитный пол (кегль, контраст) действует всегда.
  • Единственное, что умеют оба, — таблица. Собранная в редакторе остаётся блочной и в знаки не переводится.

Шапка: «назад» — вернуться в переписку, черновик сохранится (строка ввода, 04); справа — отправить, не выходя.

Верхний ряд — текст, то же, что знаки быстрого оформления: Ж, К, Ч (подчёркнутый), З (зачёркнутый), М (маркер), код, цитата, список, заголовок. Подставляют быстрое оформление к выделенному (02).

Нижний ряд — вставить и блок: картинка внутрь сообщения, ссылка, ссылка на файл в облаке, геоданные, ответ @, таблица, эмоджи, разделитель и { } — свойства блока (03). Вставка картинки, ссылки на файл и прочего внутрь сообщения — только здесь.

Печатают прямо в предпросмотре: где курсор, туда и текст. Нажатие на блок выбирает его — для свойств.

Кнопки — две строки по девять, без прокрутки: на 360 dp каждая около 34 dp — по пальцу.

выделено «в субботу в 9:00»
  • Выделили — над выделением чёрная полоска с тем же набором, что в верхнем ряду; включённое — зелёным. Кнопки, которые к части текста не применимы (цитата, список, заголовок — они про весь блок), в верхнем ряду гаснут.
  • Нажатие подставляет быстрое оформление — ту же сущность, что дают знаки **…**: отдельного «редакторского жирного» нет. Это и есть единственный способ выделить часть узла.
  • Цвет части текста задать нельзя — цвет и размер есть только у блока целиком (03).

Нажатие на блок выбирает его (зелёная обводка, бирка «блок 2 · абзац»), { } в нижнем ряду открывает его свойства на месте клавиатуры.
  • Фон — цвет из палитры темы или картинка (под текст ляжет подложка — иначе защитный пол по контрасту выкинет оформление).
  • Цвет текста, размер, выравнивание — для всего блока. Цвета — именованные из палитры, у каждого значение для светлой и тёмной темы; произвольного цвета нет.
  • Разделитель после блока — толщина или «скрыт», цвет.
  • У блока с вложением добавляется положение: во всё сообщение (720), в половину (360) слева или справа с обтеканием, сверху, снизу.
  • Меняется только тронутое. Остальное — по умолчанию, и подпись внизу говорит это прямо. «Сбросить блок» убирает все свойства блока.

Вставить JSONПрименить
вкладка JSON того же блока
  • Вкладки «Свойства» и «JSON» — одно и то же: правка в одной сразу видна в другой. JSON — для того, кто хочет задать точно или вставить готовое (бот, шаблон).
  • В JSON только изменённое — принцип «добавление свойств, замещение умолчания». Пустой style — блок по умолчанию.
  • Проверка перед «Применить»: незнакомый тип блока, цвет не из палитры, нарушение защитного пола — строка красным и что не так; применить нельзя. Так JSON не становится обходом правил.
  • Цвета — именами палитры (accent, amber-soft), а не кодами: в тёмной теме у имени своё значение.

Нижний ряд кнопок вставляет новый блок под курсором — один блок, один элемент массива:
  • 🖼 Картинка — из галереи, сразу выбор размера (720 во всё, 360 в половину) и положения; без превью, живёт по правилам сообщения.
  • 🔗 Ссылка — три режима из §3.1: без оформления, кнопка (домен крупно, путь обрезан), карточка со страницы.
  • ☁ Файл в облаке — кнопка-ссылка: файл скачивают браузером, на сервере TIMA он не лежит (в группах и каналах файлы — только так, §6.1).
  • 📍 Геоданные — картинку карты делает отправитель, кнопка открывает внешнюю карту.
  • @ Ответ — блок: имя на цветном фоне с полосой, вторая строка — что влезло из сообщения; нажатие — переход к нему.
  • ▦ Таблица — до 4 столбцов в пузыре на телефоне; объединение — кнопкой по выделенным ячейкам. Собранная здесь таблица остаётся блочной.
Блок перетаскивается долгим нажатием — порядок блоков и есть порядок элементов массива.
