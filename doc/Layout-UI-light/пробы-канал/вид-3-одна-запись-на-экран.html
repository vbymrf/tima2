В3 · Одна запись на экран проба

Лента листается по одной записи: запись занимает весь экран, следующая встаёт на её место целиком (прокрутите — лента защёлкивается). Тогда «+ / −» могут висеть справа на одном месте: на экране одна запись, и вопроса «к какой» нет. Так устроены «Слайды» в «Медиа».

текстовая запись: длинная режется
Длинная в экран не входит: текст обрезается, «читать дальше» раскрывает его листом снизу, как текст поста в «Медиа». Короткая — одна строка на весь экран.

Что даёт

  • Привязка «+ / −» однозначна без всякой геометрии: запись на экране одна.
  • Хорошо для фото и коротких видео — то, ради чего «Слайды» и заводились.

Чего стоит

  • Объявление в одну строку занимает весь экран — лента из коротких записей становится листанием пустоты.
  • Длинную запись не дочитать на месте — нужен лист раскрытия.
  • «Назад» и переход к сообщению листают целыми экранами, а поиск по ленте теряет «что было рядом».
