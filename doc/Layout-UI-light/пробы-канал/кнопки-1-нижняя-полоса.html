К1 · Нижняя полоса проба

Кнопки ленты уходят из ленты в полосу под ней, на функциональной подложке. Полоса постоянная: недоступная кнопка бледнеет, а не исчезает — иначе лента прыгала бы на высоту полосы. Рядом с «вниз» — сколько новых записей ниже.
