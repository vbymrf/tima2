Что здесь

  • Подокно, а не перебор по кругу. Настроек три и они независимы: 2 × 2 × 2 — восемь состояний. Кнопка, перебирающая восемь, не даёт угадать следующее.
  • «Меню» показано тут же строкой разделов. Слово «меню» ничего не говорит о том, что получится; строка «Все · Работа · Дом · Общий · Телефон» и есть ответ.
  • Порядок разделов от вида не меняется: «Все» первым, «Телефон» последним — иначе переключивший отображение ищет раздел заново.
  • Галки — квадратные, а не круглые. Круг у нас означает «одно из», квадрат — «сколько угодно, в том числе ничего». Ни одной галки — тоже ответ: тогда работает порядок по умолчанию.
  • Порядок по умолчанию: имя → ник → телефон → «Без имени». Он же подставляет первую строку, если выбранного поля у человека нет. Первое выбранное встаёт первой строкой, остальные — второй через «·».
  • Обрезается вторая строка, первая — никогда: по ней человека узнают.
  • Пустое поле не рисуется вовсе. Нет ника — строки нет, а не «@—».
  • Выключенный поиск переносит «＋» вниз справа, в зону-3, где у нас стоят главные действия. Другого места нет: в шапке два знака уже заняты.
  • Выключенный «показывать тех, кого нет в TIMa» гасит весь раздел «Телефон». Контакты при этом остаются в книге — их просто не видно.
