# ADR-0049. Список — контейнер; номера узлов в разметке v2

**Дата:** 2026-10-19
**Статус:** принят — решения заказчика 2026-10-19: «Линейный порядок блоков — это хорошо. Отсутствие
номера — нет»; «Список должен быть как ячейка… он и есть элемент-контейнер, с возможностью скрывать и
раскрывать его»; «1. каждый пункт, заголовок виден. Стрелка свернуть и развернуть 2. автор, делаем
кнопку свойства списка в Разметка: а) Развернуть по умолчанию б) Показать без отступа… 3. Все в ячейку
списка, не вмещается, не отправляется… 4. Цитата — элемент абзаца 5. v2, сообщения удалить v2 формата»;
«одна кнопка» (Код), «автоматическая подстановка текста, видим в редакторе, редактируется стандартно»
(«Без имени»), «на весь список».
**Заменяет частично:** [ADR-0048](0048-markup-v2-spans-and-live-marks.md) §2 (номеров узлов нет).
**Порядок работ:** [doc_mig/ПЛАН-(СП)-СПИСКА-И-ЛЕНТЫ.md](../../doc_mig/ПЛАН-(СП)-СПИСКА-И-ЛЕНТЫ.md).

## 1. Номера узлов в v2

Блоки по-прежнему идут линейно, в порядке документа (сверху вниз, вложенное — после своего блока).
Блок с текстом **называет свои узлы сам**: `"n":3`, у цитаты из нескольких строк — `"n":[3,4]`. Поле
`nodes` (число) и счёт по умолчанию убраны. Номер — место узла в теле, с единицы.

```json
{"v":2,"blocks":[{"type":"heading","level":1,"n":1},{"n":2,"e":[["b",0,6]]}]}
```

Ошибка остаётся местной: блок со ссылкой на несуществующий узел ловит проверка разметки, а не
сдвиг счёта у всех следующих; узлы незнакомого блока от будущей версии названы прямо.

**Формат v2 переопределён, а не заменён на v3** — решение заказчика: v2 нигде не раздавалась (сборка
179, четыре тестовых телефона), сообщения прежнего вида v2 заказчик удалил. Поэтому вектор
`markup_json_v2` заменён новым — это смена формата решением заказчика, а не правка вектора под тест.
v1 читается по-прежнему.

## 2. Пункт списка — контейнер

Пункт списка — как ячейка ряда: свой узел-заголовок (`"n"`), под ним **свои блоки** — абзацы,
заголовки, цитаты, код, разделитель, виджеты ячейки — и вложенный список. Ряда в пункте нет.

```json
{"type":"list","style":{"fold":"closed"},"children":[
  {"type":"list_item","n":4,"children":[
    {"type":"list","children":[
      {"type":"list_item","n":5,"children":[{"type":"quoted","widget":{"ref":{"kind":"group","container":"g-1","message":42},"author":true}}]},
      {"type":"list_item","n":6,"children":[{"type":"code_block","n":7}]}
    ]}
  ]}
]}
```

- Порядок детей пункта: блоки текста, виджеты, затем вложенный список.
- Вложенный список — только внутри пункта на ступень выше: второй уровень — под первым, третий — под
  вторым.
- Цитата остаётся видом абзаца: строки текста, без вложенных блоков.

## 3. Сворачивание и свойства списка

- У пункта с содержимым — стрелка: «▸» свёрнут, «▾» развёрнут; заголовок виден всегда. Читатель
  переключает у себя, это не сохраняется.
- Свойства **всего списка** задаёт автор кнопкой «Список» в разделе «Разметка»; в теле — стиль блока
  `list`:
  - `"fold":"closed"` — показывать свёрнутым; нет ключа — развёрнутым («Развернуть по умолчанию»);
  - `"indent":"flat"` — без отступа: вложенное с начала строки, без маркера ребёнка, отступ пункта — на
    ширину точки.
- Не помещается в пункт (виджет шире места с учётом отступа) — сообщение не отправляется; «без
  отступа» даёт место.

## 4. Редактор

- Список в документе редактора — отдельный кусок, как ряд: у пункта ступень (1–3), заголовок,
  содержимое (набранное со знаками) и виджеты.
- `- ` в начале строки («Знаки md» включены) и «Абзац ▾ → Список» превращают строку в пункт.
- Ступень 2 без пункта ступени 1 над ней (и 3 без 2) не бывает: над ней встаёт пункт «Без имени» —
  обычный текст, правится как любой.
- Строка ввода держит список строками со знаками: виджетов в ней нет.

## 5. Одна кнопка «Код»

«Абзац ▾ → Код» убран. Кнопка «Код»: выделено внутри строки — код в строке (отрезок `c`); выделены
целые строки или курсор на пустой строке — блок кода.

## Следствия

- Клиент до 180 разметку v2 с номерами не разберёт — покажет текст без оформления (как и прежнюю v2
  клиент до 179).
- Сервер разметку не разбирает — выкатка не нужна.

## Отвергнуто

- **v3 вместо переопределения v2** — v2 не раздавалась; лишняя версия навсегда осталась бы в чтении.
- **Счёт узлов без номеров (v2 в 179)** — одна ошибка сдвигает всё после неё; незнакомый блок от
  будущей версии сбивает счёт.
- **Список строками со знаками и в редакторе** — в строку не положить виджет и блок кода.
