# Мастер создания: четыре раздела

> **Переписан 2026-09-04** по решению заказчика. Прежний вид — единый список из пяти
> типов — отменён: на входе **четыре раздела**, вид группы выбирается **внутри** раздела.
> Модель — [ADR-0019](../adr/0019-message-level.md) и
> [communities.md](../01-product/communities.md); макет —
> [`Layout-UI-light/телефон/подокна/создание-группы.html`](../Layout-UI-light/телефон/подокна/создание-группы.html)
> (тёмная тема — `Layout-UI-dark/подокна/`).
>
> Точки входа: **плюс в салатовом кружке** — каталог окна 2 и страница владельца, вкладки
> «Группы» и «Коллекции».

## Шаг 1 — Раздел

::: modal
## Что создаём?

(*) **Группа** — общение несколькими участниками. Личная или публичная
( ) Канал — публикации для подписчиков  `скоро`
( ) Сообщество — контейнер: группы, каналы и звуковые чаты  `скоро`
( ) Звуковой чат — голосовая комната внутри сообщества  `скоро`

[Далее]* [Отмена]
:::

> **Три раздела показаны серыми и не выбираются.** Замысел виден целиком, а нажать нельзя
> — это честнее, чем притвориться, будто группа единственное, что бывает. У неактивных
> круг выбора пунктирный: «не выбирается», а не «выключено».
>
> **Круг слева — он же кнопка «?»**: нажатие на строку выбирает, нажатие на круг
> открывает подокно с объяснением. Отдельного значка помощи нет.

## Шаг 2 — Вид группы

::: card

(*) **Личная** — сообщения зашифрованы. Поиском не находится, зовут по знакомству  `E2E`
( ) **Публичная** — находится поиском. Открытый и закрытый доступ участников

[Далее]*

:::

> **Вид не меняется после создания.** От него зависит шифрование, а перешифровать «на
> месте» нельзя — только создать новую группу. Это сказано на экране, а не в справке.

## Шаг 3 — Вступление

::: card

( ) **Открытая** — нашёл и вступил сам
(*) **Закрытая** — подал заявку, админ разрешил

[Далее]*

:::

> **У личной группы выбор закрыт: она всегда закрытая.** Это не запрет, а следствие: её
> не находят поиском, а «вступить самому» требует сначала найти. Единственный путь —
> карточка от знакомого и заявка админу ([ADR-0018](../adr/0018-personal-group-visibility.md) п. 7).
> Причина показана на экране, а не спрятана.

## Шаг 4 — Значок, название, описание

::: card

[📷 Значок]

Название
[_________________________]{required}

Описание
[_________________________]{rows:3}

[Создать]*

:::

> **Описание — это первое сообщение уровня 0** ([ADR-0019](../adr/0019-message-level.md)
> §4), а не особое поле группы. Отсюда: его видно всем, кому открыта карточка, и оно
> подчиняется общему пределу в 4096 знаков.

## Завершение

::: alert success
Создано. Создатель — owner.
[Позвать участников]* [Положить на страницу] [Открыть]
:::

> **«Положить на страницу»** — то, что раздаёт личную группу: карточка становится видна
> контактам владельца ([ADR-0018](../adr/0018-personal-group-visibility.md) п. 2–3).
>
> При создании личной группы выполняется первая ротация группового ключа: wrapped_GK
> каждому устройству приглашённых ([crypto-protocol.md](../03-security/crypto-protocol.md) §4).

## Права на создание

| Кто | Может создать |
|-----|---------------|
| Полный аккаунт | Всё |
| Временный аккаунт | Только личные группы (до апгрейда) — [key-lifecycle.md](../03-security/key-lifecycle.md) §7 |

## Чего в этом мастере нет намеренно

Названо, чтобы не считалось потерянным при переписывании.

| Что было в прежней редакции | Почему нет сейчас |
|---|---|
| Размещение в сообществе, авто-сообщество для звукового чата | сообществ нет; вернётся вместе с разделом «Сообщество» |
| Уровень доступа `preview` / `open` / `restricted` | **отменён** [ADR-0019](../adr/0019-message-level.md): вместо него две оси и уровень сообщения |
| Премодерация, медленный режим, «только ветки» | модерация — отдельный предмет, ни одна её часть не описана |
| Инвайт-ссылки участникам | вместе с заявками на вступление |
| Шаг «Участники» отдельным экраном | стал действием после создания: «Позвать участников» |
