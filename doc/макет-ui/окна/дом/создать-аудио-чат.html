Замечания

Кого позвать — не спрашивается. Комната появляется в общем списке аудио-чатов, приглашений нет.
Удалить комнату нельзя. Создание есть, обратного действия нет — список аудио-чатов может только расти.
Выйти из формы нечем — как и у создания группы и канала.
