Закрыть форму, не создавая, нельзя: кнопки «Отмена» нет, а кнопка «Создать группу» на время формы исчезла. Форма закроется сама после успешного создания.

Замечания

Выйти из формы нечем. Ни «Отмена», ни «✕». Единственный способ убрать её с экрана — создать группу или уйти с окна и вернуться.
Участники задаются один раз. После создания состав не меняется: ни добавить, ни убрать в приложении нельзя.
Телефоны вводятся строкой через запятую, без проверки на месте, без выбора из контактов и без подсказок. Ошибка в одном номере становится видна только по ответу сервера.
