Замечания

Новое приходит только по «⟳». Живой доставки в канале нет: пока не нажать обновление, лента остаётся такой, какой была при открытии.
Отписаться нельзя. Подписка есть — в каталоге на «дом», обратного действия нет нигде.
У постов нет ни времени, ни автора, ни вложений — только текст с разметкой.
