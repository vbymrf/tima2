Макет UI — архитектура интерфейса

Что есть в приложении сегодня: окна, подокна над ними, переходы между ними. Снято с App.kt 2026-08-17, версия клиента 0.6.5. Правила раздела — README.md.

Оформление здесь не эталон. Цвета и отступы — умолчания Material 3, потому что в коде стоит пустой MaterialTheme {}. Правьте токены.css: это стартовая точка стиля, а не то, чему приложение обязано соответствовать. Обязательны состав элементов, условия их появления и переходы.

Ветвь 1. Без аккаунта

Вход по номеру

Начальное окно, если сохранённой сессии нет
вход-телефон
Адрес сервера, номер. Развилка: код по SMS или QR с другого устройства.
вход-код
Код из SMS + необязательная секретная фраза. Пусто → новый аккаунт.
  • номер-занят — развилка при конфликте личности
  • начать-заново — необратимо
фраза
12 слов показываются один раз. Только у нового аккаунта.

Вход по QR

Вторая ветвь той же развилки: ни SMS, ни фразы на этом устройстве
вход-по-qr
Название устройства → QR → ожидание. Подтверждает телефон, где аккаунт уже есть: дом → подключить устройство. Успех ведёт прямо в дом.

Ветвь 2. С аккаунтом

Главное окно

Начальное окно, если сессия сохранена
дом
Единственный узел с аккаунтом: список чатов, группы, каналы, аудио-чаты, своё имя, диагностика, фоновый режим, устройства, выход и удаление аккаунта — всё в одном прокручиваемом столбце. Отдельного окна настроек нет.
  • создать-группу — на месте
  • создать-канал — на месте
  • создать-аудио-чат — на месте
  • убрать-чат — долгое нажатие на чате
  • присоединить-аккаунт — по фразе
  • подключить-устройство — после скана QR
  • отключить-устройство — необратимо
  • удалить-аккаунт — необратимо

Переписка

Из «дом» — из списка, из «Заметок», по номеру, из контактов
чат
Личная переписка. Она же «Заметки», когда собеседник — вы сами. Отсюда — звонок (📞 / 📹).
чат-группа
Тот же composable с isGroup = true: автор в пузыре, нет «✓✓», нет «печатает…», нет ответа на сообщение. Звонок — приглашение всем.
контакты
Телефонная книга, отфильтрованная по тем, кто есть в TIMA. Только там, где она доступна платформе. Отсюда — чат и звонок.

Вещание и голос

Из «дом», из своих списков
канал
Лента постов. Поле ввода — только у владельца, остальным строка «Читаете канал».
аудио-чат
Постоянная голосовая комната с ролями: слушатель поднимает руку, владелец выдаёт слово.
звонок
Вытесняет любое окно. Не подокно: содержимое под ним не рисуется вовсе (return@Surface). Завершение возвращает туда, где были.

Чего в интерфейсе нет

Не «не нарисовано», а отсутствует в приложении. Перечислено потому, что по карте это не видно: отсутствия не выглядят никак.

НетЧто вместо
окна настроек всё вперемешку в «дом»: имя, диагностика, фоновый режим, устройства, выход, удаление аккаунта
профиля — своего и чужого одно поле «Ваше имя» в «дом»; у собеседника — имя и номер строкой в шапке чата
нижней панели переключения окон всё из «дом», возврат «←». Пяти базовых окон из ТЗ нет
поиска по переписке поиск есть только в контактах, по имени и номеру
списка звонков звонок нигде не остаётся: завершился — исчез
окна уведомлений полоска «нет связи» в «дом» и чате; в остальном молча
медиа-ленты, историй, коллекций, личных страниц, сообществ описаны в doc_UI как замысел; в коде их нет
смены аватара, темы, языка нет ни того, ни другого, ни третьего

Замечания по существу

Окна входа и «дом» залезают под статусбар. Они рисуются общей ветвью App.kt:409 — Column с прокруткой и отступом 24 dp, без windowInsetsPadding(safeDrawing). Вставки применяют только чат, контакты, канал, аудио-чат и звонок. На страницах таких окон полоса статуса розовая.
«Дом» — один столбец на 770 строк кода. Двадцать разнородных блоков без группировки и без возможности свернуть: чтобы дойти до «Выйти», нужно прокрутить через диагностику связи, каталог каналов и создание аудио-чата. Удаление аккаунта — в самом низу, рядом с выходом.
Списки — это кнопки. Чат, группа, канал, аудио-чат отрисованы как Button во всю ширину, залитые основным цветом. Поэтому список выглядит стеной фиолетовых плашек, а не списком, и в нём нет ни аватара, ни времени, ни разделителей.
Клавиатура перекрывает ввод в «дом». imePadding() есть у чата и канала, у «дом» нет — а поля ввода там есть («Ваше имя», «Новый чат», названия при создании).
