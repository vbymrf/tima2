# План: «Поделиться» в TIMA — ссылка, текст, файл из другого приложения

Заведён 2026-10-23 по слову заказчика: «Делаем план поделиться. Туда вопросы». Повод — живая
проверка 228: ссылки Rutube из «Поделиться» в их приложении играют в окне TIMA, а сама TIMA в
списке «Поделиться» Android отсутствует. Заказчик: «если это ссылка на видео — открываем как
редактор, открыли виджет видео. Если что другое — то другое».

Связанное: [ПЛАН-(ВМ)](ПЛАН-(ВМ)-ВОСПРОИЗВЕДЕНИЯ-МЕДИА.md) §3.3 (какие ссылки играют), §3.6
(виджет «Видео»); [ПЛАН-(РС)](ПЛАН-(РС)-РЕДАКТОРА-СООБЩЕНИЙ.md) (редактор);
[ПЛАН-(ПН)](ПЛАН-(ПН)-ПИН-КОДА.md) (замок при входе); [ПЛАН-(ПФ)](ПЛАН-(ПФ)-ПЕРЕДАВАЕМЫХ-ФАЙЛОВ.md)
(файлы).

**Состояние: вопросы у заказчика (§5). Код не начат.**

---

## 1. Что есть сейчас

| | Есть | Нет |
|---|---|---|
| Android, `AndroidManifest.xml` | приём `MAIN`/`LAUNCHER` и своих ссылок `tima://link` | **приёма `SEND`** — поэтому Android не показывает TIMA в «Поделиться» |
| Редактор | вставка «Видео», «Аудио», «Поток», «Ссылка» руками; список ссылок из буфера — каждая своим виджетом | открытия редактора с готовым содержимым снаружи |
| Ссылки | вид по самой ссылке (`MediaLinks.kindOf`), карточка со страницы (`LinkCardsOverHttp`) | — |

Что присылают приложения (проверить на телефонах первым шагом, ПД1): Rutube, YouTube, VK —
`ACTION_SEND`, `text/plain`, в `EXTRA_TEXT` ссылка, иногда с названием перед ней; галерея —
`image/*` и `video/*` с `EXTRA_STREAM`; несколько файлов — `ACTION_SEND_MULTIPLE`.

## 2. Как будет (предложение агента)

1. **Объявление.** `MainActivity` (или отдельное лёгкое окно приёма) объявляет `SEND` для
   `text/plain`; картинки и файлы — по ответу на ПД-В2.
2. **Выбор переписки.** Список переписок в режиме выбора, поиск сверху. Замок пин-кода (ПЛАН-(ПН))
   спрашивается до списка.
3. **Редактор по содержимому** — переписка открывается с редактором:

   | Прислано | Что открывается |
   |---|---|
   | ссылка, которая играет в окне TIMA (YouTube, Rutube, VK, mp4…) | форма «Видео»: ссылка подставлена, описание — из текста рядом со ссылкой, нет — из названия страницы; дальше метки и отправка |
   | ссылка на звуковой файл | форма «Аудио»; m3u8 — «Аудио» или «Поток» по содержимому, как при вставке |
   | другая ссылка | «Ссылка» кнопкой или карточкой (ПД-В4) |
   | несколько ссылок | список, как вставка из буфера: каждая своим виджетом |
   | текст без ссылки | текст в редакторе |
   | картинка, видео, файл | по ответу на ПД-В2 |

4. **Журнал.** Код `SHARE-IN`: что пришло (вид, число), куда открылось; без самих ссылок и текста.

## 3. Порядок

| | Что | Упирается в |
|---|---|---|
| ПД1 | Проверка на телефонах: что именно присылают Rutube, YouTube, VK, браузер, галерея (`EXTRA_TEXT`, `EXTRA_SUBJECT`, тип) — таблица в этот план | — |
| ПД2 | Приём `SEND` `text/plain`, выбор переписки, открытие редактора с текстом или ссылкой; журнал `SHARE-IN` | ПД1, ответы §5 |
| ПД3 | Ссылка → форма виджета по виду ссылки, описание из присланного текста или названия страницы | ПД2 |
| ПД4 | Картинки и файлы (`image/*`, `video/*`, `SEND_MULTIPLE`) — если ПД-В2 «да» | ПД2 |
| ПД5 | Ярлыки собеседников в системном «Поделиться» (Direct Share) — если ПД-В1 «да» | ПД2 |

## 4. Чего план не делает

- Не меняет, какие ссылки играют в окне TIMA, — это ПЛАН-(ВМ) §3.3.
- Не отправляет без редактора: присланное всегда открывается для проверки перед отправкой
  (иначе — вопрос ПД-В3).

## 5. Вопросы

| № | Вопрос | Варианты агента |
|---|---|---|
| ПД-В1 | Выбор переписки | 1а#) список переписок с поиском; 1б) он же **и** ярлыки последних собеседников прямо в системном «Поделиться» (ПД5) |
| ПД-В2 | Что принимаем | 2а#) сначала текст и ссылки (ПД2–ПД3), картинки и файлы — следом (ПД4); 2б) всё сразу; 2в) только текст и ссылки |
| ПД-В3 | Отправка | 3а#) всегда через редактор — человек видит и правит; 3б) текст и обычную ссылку — сразу в переписку, видео — через форму |
| ПД-В4 | Ссылка не на видео и не на звук | 4а#) кнопка «Перейти», название — из присланного текста или страницы; 4б) карточка со страницы (картинка и описание) |
| ПД-В5 | Куда можно поделиться | 5а#) личные, группы и каналы, где можно писать; 5б) только личные и группы |
| ПД-В6 | ПК | 6а#) не делаем: в Windows нет общего «Поделиться» для приложений вроде нашего, ссылку вставляют из буфера; 6б) перетаскивание ссылки или файла в окно переписки |
