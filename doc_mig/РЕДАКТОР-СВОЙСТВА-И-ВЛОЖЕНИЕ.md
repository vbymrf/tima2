# Редактор: что во что вкладывается и какие свойства где действуют

Заказчик 2026-10-20: «Сейчас непонятно, что работает для каждого типа содержимого… Проверь сам по
коду. Создай таблицу». Проверено по коду сборки 182: сборка тела — `ComposedBodiesOverKodium`,
проверка — `MarkupRules`, показ у получателя — `RichMapper`, `RichBody`, `RichWidgets`, редактор —
`EditorScreen`, `EditorLayout`, `EditorList`, `ComposedStyle.applicable`. Решения —
[ADR-0044](../doc/adr/0044-editor-markup-rows-cells-widgets.md), [ADR-0048](../doc/adr/0048-markup-v2-spans-and-live-marks.md),
[ADR-0049](../doc/adr/0049-list-container-node-numbers.md), [ADR-0050](../doc/adr/0050-quote-underlay-properties-links.md).

Таблица держится в одном месте: меняется код свойств или вложения — правится здесь же, в том же коммите.

## 1. Что бывает в сообщении

| Элемент | Как ставится в редакторе | В теле (разметка) |
|---|---|---|
| Абзац | набор; «Абзац ▾ → Абзац» | `paragraph` |
| Заголовок 1–3 | «Абзац ▾»; `# `, `## `, `### ` | `heading`, `level` |
| Цитата | «Абзац ▾ → Цитата»; `--> ` | `quote` (строки) |
| Список, 1–3 уровня | «Абзац ▾ → Список: 1 2 3»; `- ` | `list` → `list_item` |
| Блок кода | кнопка «Код» на целых строках или пустой строке; ```` ``` ```` | `code_block` |
| Разделитель | `---` | `divider` |
| Ряд (строки × столбцы) | «Разметка → Ряд» | `flex` → `row` → `cell` |
| Виджет во всю ширину | «Вставка» | `flex` с одной ячейкой 100 % |
| Подкладка | «Вставка → Подкладка» | `underlay` — только в конце |
| Ответ | «Вставка → Ответ» | `reply` |
| Метка «Продолжение» | «Вставка → Подкладка → Новое продолжение» (группа) | в тело не идёт: отдельное сообщение |

Виджеты: картинка, ссылка (текстом, кнопкой, карточкой), облако, место, контакт, эмоджи, подборка,
подкладка, ответ. Опрос, мероприятие, видеоклипы, аудио — заглушки ([ПЛАН-(ВД)](ПЛАН-(ВД)-ВИДЖЕТОВ.md)).

|---|---|---|---|---|---|---|---|---|---|---|

Порядок под заголовком пункта: блоки текста, виджеты, вложенный список. В ячейке: текст, виджеты.

## 3. Стиль: что где действует

«Стиль» показывает только кнопки, которые действуют на выбранное (`ComposedStyle.applicable`).
Отметки — у получателя и в редакторе одинаково.

| Элемент | Фон | Цвет | Размер | Выравн. | Отступ | Раздел. и его цвет | По вертикали |
|---|---|---|---|---|---|---|---|
| Абзац, заголовок | да | да | да | да | да | да | — |
| Цитата | да | да | да | да | да | да | — |
| Блок кода | да (поверх серого) | да | да | да | да | да | — |
| Список целиком | да — у списка | да — на все пункты без своего | да — так же | да — так же | да | да | — |
| Пункт списка | да | да | да | да | да | да — после пункта | — |
| Ряд целиком | да — у ряда | да — ячейкам без своего | да — так же | да — так же | да | да | — |
| Ячейка | да | да | да | да | да | да | да — в «Свойствах» |
| Виджет во всю ширину | да | нет¹ | нет | нет | да | да | — |
| Виджет в ячейке, в пункте | стиль ячейки, пункта | | | | | | |
| Подкладка | да | нет | нет | нет | да | да — разделитель склеенных | — |
| Ответ | нет | нет | нет | нет | нет | нет | — |
| Разделитель (`---`) | нет | нет | нет | нет | нет | нет | — |
| Метка «Продолжение» | нет | нет | нет | нет | нет | нет | — |

¹ Цвет ссылки — в её «Свойствах»: «Стиль → Свойства → цвет».

**Наследование.** Ряд → ячейки, список → пункты, ячейка и пункт → всё, что в них: цвет, размер и
выравнивание контейнера действуют там, где у вложенного своих нет. Фон, отступ и разделитель — только у
самого контейнера.

Кусок текста из нескольких строк разных видов (абзац, цитата, код) — один стиль на все его строки.

## 4. «Стиль → Свойства»: своё у элемента

| Элемент | Свойства |
|---|---|
| Список (и любой его пункт) | «Развернуть по умолчанию», «Без отступа» — на весь список |
| Ячейка | по вертикали: сверху, по центру, снизу |
| Ссылка | вид — текстом, кнопкой (по умолчанию, «Перейти · домен»), карточкой (из сети по выбору); цвет |
| Подборка, подкладка | имя владельца; переход — один из пяти (2026-10-20): «Без перехода», «Само сообщение» (зелёная полоса справа), «Продолжить чтение», «Свой текст» (до 40 знаков), «Стрелка»; строк — целиком, 1, 2, 3. Подборка показывает текст и первое фото, подкладка — исходное целиком внутри пузыря ([ADR-0050](../doc/adr/0050-quote-underlay-properties-links.md) §1) |
| Облако | вид: файл, документ, аудио, видео |
| Остальное | своих свойств нет |

## 5. Пределы

| Что | Предел | Нарушено |
|---|---|---|
| Ряд | до 7 столбцов, до 20 строк | не помещается — не отправляется |
| Ширина ячейки | текст 35 dp, картинка и ссылка 96, карточка, подборка и ответ 140, облако, место и контакт 120, эмоджи 48 | ряд красный, не отправляется |
| Список | до 3 уровней; 2-й только под 1-м, 3-й под 2-м — иначе сверху «Без имени» | — |
| Виджет в пункте | помещается в 260 dp − 14 dp − 14 dp на ступень (без отступа — 246) | «Пункт списка не помещается» |
| Подборка уровня | до 100 ссылок, на этом устройстве | «Добавить в подборку» отказывает |
| Подкладок за раз | до 10; «Списком» — до 100 | лишнее не отмечается |
| Картинок в сообщении, рядов | как у `MarkupRules` (`MAX_IMAGES`, `MAX_ROWS`) | не отправляется |
