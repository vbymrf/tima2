## Как прогнать

**ПК** — проверки с выходом в сеть, включаются переменной (в обычном прогоне молчат):

```bash
cd client
export TIMA_LIVE_MEDIA=1
./gradlew :core:core-media:jvmTest --tests 'io.tima.core.media.OwnPlayerLiveTest' --tests 'io.tima.core.media.WebPlayerLiveTest'
./gradlew :core:core-network:jvmTest --tests 'io.tima.core.network.MediaResolveLiveTest'
```

На время проверки браузерного движка на экране ПК открывается окно с видео.

**Телефоны** — открыть ссылку в переписке → «Перейти» → окно; «Другой проигрыватель» — второй
движок. Признак — строки журнала `PLAYER`: «открыто … own/web», «пошло … own/web» (РЕЕСТР).
