# План: группа закреплённых сообщений

Заведён 2026-10-21 по слову заказчика: «Делаем буффер закрепленных сообщений. Можно разместить либо одно
сообщение на чат (группу и т.д), либо группу сообщений»; после разбора — «Для группы делаем название…
Удалить все, часть, Заменить, Добавить, Отмена», затем «4. Составляй планы. По Группе закрепленных пиши».
Продолжает [ПЛАН-(ЗО)](ПЛАН-(ЗО)-ЗАКРЕПЛЕНИЯ-И-ОПИСАНИЯ.md) (ЗО1, ЗО3): там закреплённое — одно.

**Статус 2026-10-21: план, работ нет.**

## 0. Что уже есть

- **Сервер** (`server/migrations/0078_pins_showcase.sql`, `server/internal/store/pins.go`,
  `server/internal/api/pins_showcase.go`): таблица `pins` — **одна строка на контейнер** (личная
  переписка, группа, канал), ключ `(container_kind, container_id)`. `GET/PUT/DELETE …/chats/{id}/pin`,
  `…/groups/{id}/pin`, `…/channels/{id}/pin`; `PUT` заменяет прежнее. Права: личная — любой из двух,
  группа и канал — модератор и выше (403 `not_moderator`). Номер — живое сообщение этого контейнера,
  иначе 409 `message_not_pinnable`. Событие `message.pinned` (`message_id`, 0 — снято; `by`). Удалили
  закреплённое — снимается само (`unpinDeletedSQL`).
- **Клиент**: `ChatPins` (`client/domain/domain-chat/.../Pins.kt`) — переписка → номер; `PinnedBar`
  (`client/feature/feature-chat/.../PinnedBar.kt`) — «Закреплено» и строка, нажатие — переход
  (`FeedJumps`), ✕ — снять у кого право; меню сообщения «Закрепить»/«Открепить»
  (`PinTags.MENU_PIN`, `MENU_UNPIN`); служебная строка «… закрепил(а) сообщение»
  (`ShowcaseWords`). Канала на экране нет — закрепление канала только на сервере.

## 1. Решения (заказчик 2026-10-21)

| Что | Решение |
|---|---|
| Сколько | **одно** сообщение или **группа** до **20** сообщений на переписку, группу, канал |
| Где хранится, кто видит, права | **как сейчас**: на сервере открыто, видят все участники, личная — любой из двух, группа и канал — модератор и выше |
| Одно → группа | закрепили второе — одно становится группой; **дубликат** не добавляется («Уже закреплено») |
| Название группы | задаётся; **не задано — «Группа сообщений»**. Задаёт тот, у кого право закреплять, нажатием на название в подокне |
| Полоса при одном | как сейчас: «Закреплено», строка сообщения, ✕ |
| Полоса при группе | «Закреплена группа сообщений.» и ниже — число и название; **на месте ✕ — число закреплённых** |
| Подокно группы | сверху название и ✕ справа; выход — ✕ или нажатие вне подокна. У каждого сообщения **три строки**, нажали — переход к самому сообщению; вид ссылки — как у подборки |
| Внизу подокна | «Удалить группу»; «Удалить сообщения» — первое нажатие показывает галочки, второе удаляет выбранные |
| «Закрепить», когда уже закреплено | выбор: **Добавить · Заменить · Удалить все · Удалить часть · Отмена** и ✕ сверху справа; нажатие вне — выйти |
| Служебная строка | **на каждое изменение**: «… обновил(а) закреплённые»; первое закрепление и полное снятие — как сейчас |
| Меню переписки | пункт «Закреплённые» — то же подокно (просмотр, галочки, удаление) |

## 2. Этапы

### ЗГ1. Сервер: список закреплённых и название

- Миграция (добавляющая) `0079_pin_lists.sql`:
  - `pin_items (container_kind, container_id, message_id, position, pinned_by, pinned_at)`, ключ
    `(container_kind, container_id, message_id)`;
  - `pin_titles (container_kind, container_id, title, set_by, set_at)`;
  - перенос: каждая строка `pins` — первым пунктом `pin_items`. Таблица `pins` остаётся (не удаляется),
    но больше не пишется.
- Новые запросы (права — как у `…/pin`):
  - `GET …/pins` — `{title, items: [{message_id, by, pinned_at_unix_ms}], max: 20}`, новые первыми;
  - `POST …/pins` — `{message_ids, mode: "add" | "replace"}`; дубликат пропускается (`already`),
    двадцать первое — 409 `pins_full`, чужое или удалённое — 409 `message_not_pinnable`;
  - `DELETE …/pins` — `{message_ids}` убирает выбранные, пустое тело — все;
  - `PUT …/pins/title` — `{title}` (до 64 знаков; пустое — снять название).
- **Прежние запросы не ломаются** (на стенде живут установленные клиенты): `GET …/pin` отдаёт последнее
  закреплённое; `PUT …/pin` — «заменить»; `DELETE …/pin` — снять все.
- Событие `message.pinned` расширяется: прежнее `message_id` (последнее закреплённое или 0) — для
  установленных клиентов; новые поля `message_ids`, `title`, `change` (`added`, `removed`, `replaced`,
  `cleared`, `renamed`). Удаление закреплённого убирает его из списка и шлёт то же событие.
- Тесты: предел 20, дубликат, порядок, права, старые запросы поверх списка, перенос строки `pins`.

### ЗГ2. Клиент: снимок закреплённых

- `ChatPins`: переписка → `PinBoard(title, ids)` вместо номера. `RemotePins` — `list`, `add`,
  `remove`, `rename`. Сервер старый (`…/pins` — 404) — прежний `…/pin`, одно сообщение.
- Событие `message.pinned` с `message_ids` — снимок целиком; без них — как сейчас.
- Тесты: снимок из события, переход с одного на группу, старый сервер.

### ЗГ3. Клиент: полоса и подокно

- Полоса: одно — как сейчас; группа — «Закреплена группа сообщений.», ниже «N · название» (или
  «Группа сообщений»), справа число вместо ✕. Нажатие на полосу или число — подокно.
- Подокно: название (у кого право — нажатие меняет), ✕ справа, выход нажатием вне. Сообщения новыми
  первыми, по три строки, вид ссылки как у подборки; нажатие — переход (`FeedJumps`), подокно
  закрывается. Не загружено — заглушка «Сообщение закреплено» и переход по номеру.
- Внизу (у кого право): «Удалить группу» (с подтверждением), «Удалить сообщения» — галочки, второе
  нажатие удаляет выбранные.
- Меню переписки: «Закреплённые» — то же подокно; пункта нет, пока ничего не закреплено.
- Метки для сценариев и строки окна — в [СЦЕНАРИИ-ПО-ОКНАМ.md](ФУНКЦИОНАЛ/АВТОТЕСТЫ/СЦЕНАРИИ-ПО-ОКНАМ.md);
  слова — на трёх языках.

### ЗГ4. Клиент: «Закрепить», когда уже закреплено

- Ничего не закреплено — закрепляется сразу, как сейчас.
- Уже есть — окно выбора: «Добавить», «Заменить», «Удалить все», «Удалить часть», «Отмена», ✕.
  «Удалить часть» открывает подокно сразу с галочками. Сообщение уже в группе — «Уже закреплено».
  Двадцать — «Добавить» недоступно, подсказка «Закреплено 20 — уберите лишние».
- «Открепить» в меню закреплённого сообщения — убирает только его.

### ЗГ5. Служебная строка, журнал, проверка

- Служебная строка: «… закрепил(а) сообщение» — первое закрепление; «… обновил(а) закреплённые» —
  любое изменение группы; «… открепил(а)» — снято всё.
- Коды журнала: закрепление (кто, что, сколько, отказ: `pins_full`, `not_moderator`).
- Тесты сервера и клиента; строка журнала работ; выкатка: **сервер раньше клиента**, на стенд — **только
  по указанию заказчика**.

## 3. Открыто

- «Удалить все» в окне «Закрепить» — понято как «снять все, новое не закреплять»; «Заменить» — снять все и
  закрепить это. Проверить толкование при приёмке.
- Канал: сервер получит список вместе с группой и личной; на экране — вместе с окном канала (как в ЗО).
