# Окно «Телефон» — что работает

Макет: [`Layout-UI-light/телефон/окна/телефон.html`](../../../doc/Layout-UI-light/телефон/окна/телефон.html);
описание — `интерфейс.md §3`; ТЗ — `doc/doc_UI/02-phone-home.md`.

**Вкладки:** Чаты · Контакты · Звонки. Построены все три: «Звонки» показывают журнал
звонков с фильтрами (сверено с кодом 2026-09-29; до этого вкладка ждала К7 и говорила об
этом словами).

**Звонок живёт своим окном, а не подокном этого** — окно 0 по макету `21-call.md`,
решение заказчика 2026-09-19. Из «Телефона» в него ведут кнопка в шапке личной
переписки, кнопки в строке контакта и в строке журнала (сверено с кодом 2026-09-29). В
шапке группы кнопки нет вовсе — не погашена, а нет: погашенная
кнопка спрашивает «почему», отсутствующая не спрашивает ничего.

| Действие | Последствие |
|---|---|
| Открыть окно | вкладка та, на которой оставили; при первом входе — «Чаты» |
| Вкладка «Чаты» | личные переписки по последнему сообщению; групп здесь нет с 2026-09-17 — они на вкладке «Группы» окна 5 (сверено с кодом 2026-09-29) |
| Нажать строку переписки | окно переписки |
| «+» в грозди | новая переписка по номеру; «этого номера в TIMA нет» — отдельный исход, не ошибка |
| Вкладка «Контакты» | книга: прочитанное с телефона плюс заведённое руками; безымянные — в конец |
| Нажать «лупу» на «Чатах» или «Контактах» | под вкладками строка поиска; запрос общий у обеих вкладок; крестик закрывает строку и очищает запрос. У «Звонков» «лупы» нет (сверено с кодом 2026-09-29) |
| Ввести в поиск | список сузился: в «Чатах» — по имени и первой строке последнего сообщения, в «Контактах» — по имени, нику или цифрам номера; ничего не нашлось — сказано словами |
| Нажать человека, который есть в TIMa | его переписка |
| Нажать человека из раздела «Телефон» | подокно «Пригласить»: СМС, звонок, «поделиться» |
| Нажать «плюс» внизу справа на «Контактах» | подокно «Новый контакт»: по номеру или по нику, имя и раздел — нет. Левее «плюса» на телефоне — «обновить», сверка с книгой сейчас (сверено с кодом 2026-09-29) |
| Нажать аватар в строке контакта | страница человека: «Что мы знаем», «Позвонить», «Видеозвонок», «Написать», «Добавить в контакты» (сверено с кодом 2026-09-29) |
| Нажать трубку или камеру в строке человека из TIMa | окно 0 — голосовой или видеозвонок. Кнопок нет, где звонить нечем (сверено с кодом 2026-09-29) |
| Нажать «Вид» последней вкладкой — на любой из трёх вкладок | подокно настроек списка: папки или меню, что показывать, чем называть людей; первая строка человека — имя, ник или имя пользователя по галкам (сверено с кодом 2026-09-29) |
| Свернуть раздел в виде «папки» | раздел закрылся, число людей осталось видно |
| Открыть вкладку без разрешения на контакты | сказано, что будет и чего не будет, и предложено разрешить |
| Открыть вкладку на ПК | сказано, что телефонной книги здесь нет и контакты добавляют вручную |
| Вкладка «Звонки» | журнал звонков: кто, «↗ видео · не дозвонился · 3:05», когда; пропущенный выделен; фильтры Все · Контактов · Незнакомые · Пропущенные (переименовано 2026-10-08); групповой звонок — строкой с «ГЗ»: аватар — страница создателя, строка — чат звонка, кнопка — повторить (автору) или войти (участнику), чата нет — «Чат удалён» (2026-10-08; в «Чатах» групп звонка больше нет); имя — книга поверх карточки, как в «Чатах»; пусто без связи — сказано про связь; число непросмотренных пропущенных — у вкладки (сверено с кодом 2026-09-29) |
| Нажать трубку или камеру в строке журнала | перезвонить тем же видом — окно 0 (сверено с кодом 2026-09-29) |
| Нажать «📞» в шапке личной переписки | окно 0 — звонок; на первом звонке телефон спрашивает про микрофон |
| Нажать логотип с именем окна | переключение окон; окно «Звонок» есть в списке, только пока звонок идёт |
| «шестерёнка» | список настроек (сверено с кодом 2026-09-29; до этого — «Устройства») |

**Раздел «Телефон» — последний и всегда последний.** В нём те, кого нет в TIMa. Отметки
«в TIMa» у строки нет: она повторяла бы одно и то же на всём списке, а на вопрос «кому
можно написать» отвечает место в списке.

**Своё имя контакта не затирается синхронизацией.** В книге два поля: прочитанное из
телефона и записанное человеком. Одно поле означало бы, что следующая синхронизация
обязана выбрать — затереть правку или навсегда перестать замечать смену имени в телефоне.

**Убранный из книги не возвращается.** Строка остаётся с пометкой: без неё синхронизация
вернула бы его из телефонной книги, и удаление выглядело бы неработающим.

**Есть в контактах — друг.** Найденный в TIMa при добавлении попадает в список друзей, и
его лента начинает читаться; убрали из книги — подписка снята.

**Сверка идёт слепым индексом.** На сервер уходит номер, а хранится он там как
`HMAC(pepper, E.164)`: обещание «сверяем, не читая» держится на этом, а не на словах.

## Нет входа

Построено и работает, но человек до этого не доберётся.

утверждения, и в отчёте они обязаны стоять раздельно (`ИНТЕРФЕЙС/ПРАВИЛО.md`).
