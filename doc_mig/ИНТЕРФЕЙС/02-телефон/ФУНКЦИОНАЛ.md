# Окно «Телефон» — что работает

Макет: `doc/doc_UI/02-phone-home.md`.

Из трёх вкладок макета (Контакты · Чаты · Звонки) построена одна — «Чаты». Рейки вкладок
нет: рисовать её ради одной значит обещать переключение, которого не будет.

| Действие | Последствие |
|---|---|
| Открыть список | переписки по последнему сообщению; пустые (только что созданные группы) идут первыми |
| Нажать строку | окно переписки |
| «+» | новая переписка по номеру; «этого номера в TIMA нет» — отдельный исход, не ошибка |
| «⚙» | «Устройства»: список своих, отключение чужого, номер сборки |
