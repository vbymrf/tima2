# Оболочка — связи

| Откуда | Действие | Куда | В коде |
|---|---|---|---|
| Любое окно | логотип с именем | Переключение окон | да |
| Любое окно (телефон) | свайп по средней зоне | соседнее окно | да |
| Переключение окон | строка окна | это окно | да |
| Переключение окон | «✕», касание мимо | назад в то же окно | да |
| Переключение окон | «Настройки» | «Устройства» | да |
| Рейка (широкий формат) | значок окна | это окно | да |
| Рейка | «Настройки» | «Устройства» | да |
| Переключение окон | строка аккаунта | этот аккаунт (окружение пересобрано) | да |
| Переключение окон | строка аккаунта при непустой очереди | вопрос «подождать или уйти» | да |
| Переключение окон | «плюс Виртуальный аккаунт» | экран заведения | да |
| Настройки | «Виртуальные аккаунты» | список своих виртуальных | да |
| Виртуальные аккаунты | «Завести» | экран заведения | да |
| Виртуальные аккаунты | «Передать» у строки | экран передачи: код и QR | да |
| Виртуальные аккаунты | «Принять аккаунт» | экран приёма: код и фраза | да |
| Экран передачи и приёма | «назад» | «Виртуальные аккаунты» | да |
| Экран приёма | «Войти в аккаунт» после успеха | принятый аккаунт | да |

## Из макета и описания, не построено

| Откуда | Действие | Куда | Чем держится |
|---|---|---|---|
| Переключение окон | блогерские окна | окна 6–7 | окон нет |
| Любое окно | «лупа» | подокно «Поиск» (`§9`) | подокно не построено |
| Любое окно | «шестерёнка» | подокно «Настройки» (`§9`) | построены три его раздела — «Профиль», «Устройства», «Виртуальные аккаунты» |

## Придумано сверх макета

| Откуда | Действие | Куда | Почему не из макета |
|---|---|---|---|
| Переключение окон | аккаунты и заведение виртуального | экраны Д10…Д12 | в макете аккаунт один, прообраза нет |
| Настройки | «Виртуальные аккаунты» | список, передача, приём | то же |
