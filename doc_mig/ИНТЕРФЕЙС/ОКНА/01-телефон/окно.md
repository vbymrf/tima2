# Окно 1 — Телефон

Макет: [`doc/doc_UI/02-phone-home.md`](../../../../doc/doc_UI/02-phone-home.md).
Переходы — [СВЯЗИ.md](../../СВЯЗИ.md). Недостающее и подменённое — [ЗАГЛУШКИ.md](../../ЗАГЛУШКИ.md).

**Что здесь.** Что человек **может сделать** в сегодняшней сборке — действиями и
последствиями, а не модулями. Строка появляется, когда поведение работает целиком: от
нажатия до последствия. Построенное, но недостижимое из приложения, живёт в разделе ниже —
и это не придирка, а разница между «готово» и «есть в репозитории».

## Вкладка «Чаты» — работает

### Вход и аккаунт

| Что человек делает | Что происходит |
|---|---|
| Вводит код страны и номер | код страны — отдельное поле, плюс нарисован и в значение не входит; номер, вставленный целиком с `+`, берётся как есть |
| «Получить код» | приходит SMS; на стенде код показан под полем — сервер отдаёт его в ответе при `TIMA_DEV_SMS` |
| Вводит код | устройство заводится, показывается секретная фраза — **один раз** |
| Номер уже занят | предлагается вход по фразе; есть выход «Другой номер» с сохранённым номером |
| Вводит фразу | вход по прежней личности; идёт с `registration_token`, а не с кодом — код одноразовый |
| «Начать заново» | новая личность на тот же номер; прежняя переписка не возвращается, показывается новая фраза |
| Подключает второе устройство | QR на ПК, подтверждение телефоном, переход по ссылке `tima://link/…` |
| Открывает «Устройства» | список своих устройств, отключение чужого, номер сборки внизу |

Номер сборки виден **на входе** и **в «Устройствах»**: первый — проверить обновление до
входа, второй — ответить на «какая версия стоит», когда что-то пошло не так.

### Переписка

| Что человек делает | Что происходит |
|---|---|
| Открывает список | переписки по последнему сообщению; пустые (только что созданные группы) идут первыми |
| Начинает новую по номеру | поиск по номеру; «этого номера в TIMA нет» — отдельный исход, не ошибка |
| Пишет сообщение | уходит в очередь, отметка меняется: ждёт → ушло → не ушло |
| Читает переписку | реплики с временем и отметками; нечитаемое остаётся строкой, а не исчезает |
| Открывает группу | то же окно, но у каждой чужой реплики виден автор |
| Видит недоступную историю | «сообщение недоступно» и полоса с кнопкой «Запросить ключ» — одна на экран |
| Запрашивает ключ | просьба уходит участникам, у которых он есть; исходы различаются: «ушла к N устройствам», «ни у кого нет», «нужна секретная фраза» |

## Построено, но недостижимо

Экраны есть, проверки зелёные, **открыть их в приложении нечем**: `feature-group` не
подключён к `shared`. Найдено 2026-08-25 при составлении карты связей.

| Экран | Что умеет | Чего не хватает |
|---|---|---|
| Новая группа | название, накопление номеров до создания, показ непозванных | входа из списка переписок |
| Состав группы | список участников с ролями, приглашение, исключение с ротацией ключа | входа из окна переписки |

Ровно поэтому такое живёт отдельным разделом: в отчётах «сделано и проверено» неотличимо
от «человек может этим пользоваться».

## Вкладка «Контакты» — наполовину

Данные готовы и проверены (5 проверок на настоящем SQL): контакт — человек, с которым уже
есть личная переписка; порядок по имени, безымянные в конце; группы в контакты не
попадают. **Экрана нет.**

Присутствия («онлайн», «была 5 минут назад») не будет, пока сервер его не отдаёт — см.
[ЗАГЛУШКИ §1](../../ЗАГЛУШКИ.md) и [ВОПРОСЫ И1](../../ВОПРОСЫ.md).

## Вкладка «Звонки» — нет

Упирается в LiveKit-клиента (К7). До него — честно пустая, без придуманных вызовов.
