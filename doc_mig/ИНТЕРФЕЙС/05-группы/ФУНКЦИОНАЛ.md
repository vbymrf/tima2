# Группы — что работает

Макет: [`телефон/подокна/чат.html`](../../../doc/Layout-UI-light/телефон/подокна/чат.html)
в групповом состоянии; описание — `интерфейс.md §9 «Чат»` («два состояния: личный чат и
групповой — авторы, упоминание, ветка»); ТЗ — `doc/doc_UI/05-group-chat.md`.

**Мастер создания группы нарисован не был.** Он описан в ТЗ
(`doc/doc_UI/33-create-group-channel.md`: пять типов — личная группа, публичная группа,
канал, аудио-чат, сообщество; четыре шага — тип, имя и описание, размещение, доступ) и
прямо назван недостающим в макете: `интерфейс.md §12` — «мастер создания группы, канала,
аудио-чата, сообщества».

| Действие | Последствие |
|---|---|
| Создать группу | название и номера накапливаются до создания; непозванные показаны отдельно, группа при этом создана |
| Открыть состав | участники с ролями; управление видно только тому, кому оно разрешено |
| Позвать по номеру | участник добавлен, ключ группы сменён |
| Исключить | участник убран, ключ сменён; если сменить не удалось — сказано словами, потому что до смены ключа исключённый читает новое |
| Написать в группу | сообщение уходит под текущей версией ключа |
| Прочитать чужое | видно, кто написал: имя и аватар внутри пузыря, полоса автора у края; вторая реплика подряд от того же — без подписи |

Живьём не проверялось: два аккаунта заведены, до групп не дошли.
