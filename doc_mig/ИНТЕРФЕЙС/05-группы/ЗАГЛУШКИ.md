# Группы — заглушки

| Что стоит сейчас | Что должно быть | Чем держится |
|---|---|---|
| Экран создания — один экран: название и номера | мастер из ТЗ `doc_UI/33-create-group-channel.md`: тип (5 видов) → имя и описание → размещение → доступ | макета нет (`§12`); придуман упрощённый экран под одну личную группу |
| Вход «Группа» в шапке списка переписок — **придуман** | зелёная кнопка «плюс» в каталоге окна 2 (`doc_UI/33`: «точки входа: каталог окна 2 [+ Создать]», `§51`, `§702`) | окна 2 нет |
| Вход «Участники» в шапке переписки — **придуман** | состав разворачивается строкой каталога (`§1081`) | то же |
| Имя участника = его идентификатор | имя человека | сервер не отдаёт имена списком |
| Название «Группа» у группы, впервые встреченной во входящем | настоящее название с сервера | приёмник не ходит за составом ради имени |
| Публичных групп нет | по протоколу сервер их умеет | клиент не умеет; ждут социального слоя |
