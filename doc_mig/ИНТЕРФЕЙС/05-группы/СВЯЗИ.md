# Группы — связи

| Откуда | Действие | Куда | В коде |
|---|---|---|---|
| Список переписок | «Группа» (вход придуман) | Создание группы | да |
| Создание | все позвались | Переписка группы | да |
| Создание | кто-то не позвался | остаётся, показывает непозванных | да |
| Переписка группы | «Участники» (вход придуман) | Состав | да |
| Состав | «назад» | Переписка группы | да |

## Из макета, не построено

| Откуда | Действие | Куда | Чем держится |
|---|---|---|---|
| Каталог окна 2 | строка группы | Переписка группы | окна 2 нет |
| Каталог окна 2 | разворот строки | Состав группы | то же |
| Окно 5 | строка своей группы | Переписка группы | окна 5 нет |
