# Вход и регистрация — что работает

**Макета нет:** вход и восстановление доступа перечислены в `интерфейс.md §12` среди
ненарисованного. Источник — только ТЗ: `doc/doc_UI/22-auth-registration.md`,
`23-auth-recovery.md`.

| Действие | Последствие |
|---|---|
| Ввод кода страны и номера | код страны — отдельное поле; плюс нарисован, в значение не входит; номер, вставленный целиком с плюсом, берётся как есть |
| «Получить код» | SMS; на стенде код показан под полем (`TIMA_DEV_SMS`) |
| Ввод кода | устройство заведено, показана секретная фраза — один раз |
| Номер занят | экран входа по фразе; «Другой номер» возвращает к вводу с сохранённым номером |
| Ввод фразы | вход по прежней личности; идёт с `registration_token` — код одноразовый |
| «Начать заново» | новая личность на тот же номер, показана новая фраза |
| Номер сборки | виден внизу экрана входа |

Проверено живьём 2026-08-25 на Realme RMX3269 и Redmi Note 8 Pro: заведены два аккаунта.
