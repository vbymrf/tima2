# Окно переписки — заглушки

| Что стоит сейчас | Что должно быть | Чем держится |
|---|---|---|
| «Участник» вместо имени автора | имя человека | имена берутся по одному через справочник; на всех сразу сервер их не отдаёт |
| Присутствия в шапке нет | «в сети», «была 5 минут назад» | сервер не отдаёт |
| Аватар автора в пузыре группы не нажимается; в шапке личной переписки аватар с именем ведут на страницу человека подокном, а не во всплывающий профиль | всплывающий профиль (`16-profile-popup.md`) | всплывающего профиля нет (сверено с кодом 2026-09-29) |
| Реакций и ответа с цитатой нет; ветка начинается не из каждого сообщения | по макету есть | реакций в клиенте нет. Ветки есть только в группе: строка «ветка · N ответов» стоит под сообщением, у которого ответы уже есть, — начать ветку у сообщения без ответов из переписки нечем (сверено с кодом 2026-09-29) |
