# Окно переписки — что работает

Макет: [`телефон/подокна/чат.html`](../../../doc/Layout-UI-light/телефон/подокна/чат.html);
описание — `интерфейс.md §9 «Чат»`; ТЗ — `doc/doc_UI/03-personal-chat.md`, для группы —
`05-group-chat.md`.

Подписей в личной переписке нет: у чужой реплики остаётся полоса автора, но ни имени, ни
аватара внутри пузыря. Так в макете, и так с 2026-08-25 в коде — до этого имя собеседника
дублировалось из шапки над каждым его сообщением.

| Действие | Последствие |
|---|---|
| Набрать и отправить | сообщение в очереди; отметка меняется: ждёт → ушло → не ушло |
| Читать | реплики с временем и отметками; нечитаемое остаётся строкой, а не исчезает |
| Открыть группу | то же окно, но у каждой чужой реплики виден автор |
| Недоступная история | «сообщение недоступно» и полоса с кнопкой «Запросить ключ» — одна на экран |
| «Запросить ключ» | просьба уходит участникам, у которых он есть; исходы различаются: ушла к N устройствам, ни у кого нет, нужна секретная фраза |
