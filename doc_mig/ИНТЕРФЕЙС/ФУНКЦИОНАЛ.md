# Функционал интерфейса: что построено и как себя ведёт

**Что это.** Описание того, что приложение **умеет сейчас** — экранами и поведением, а не
модулями. Не макет и не план: макет говорит, как должно быть, дорожная карта — что
делать, а этот файл отвечает на вопрос «что человек может сделать в сегодняшней сборке».

**Как этим пользоваться.** Сформировал функционал — записал сюда. Строка появляется, когда
поведение **работает целиком**, от нажатия до последствия. Наполовину сделанное живёт в
[ЗАГЛУШКАХ](ЗАГЛУШКИ.md), а не здесь.

**Почему отдельно от `doc/`.** Там описан продукт, каким он задуман. Здесь — состояние
работы. Смешивать нельзя: документ, где задуманное и сделанное лежат вперемешку, через
месяц не отвечает ни на один вопрос.

## Окно «Телефон»

Единственное построенное окно. Вкладок нет: построена одна — «Чаты», и рисовать рейку
вкладок ради одной было бы обещанием, которого интерфейс не держит.

### Вход и аккаунт

| Что человек делает | Что происходит |
|---|---|
| Вводит код страны и номер | код страны отдельным полем, плюс нарисован и в значение не входит; вставленный целиком номер (с `+`) берётся как есть |
| Нажимает «Получить код» | приходит SMS; на стенде код показан под полем — сервер отдаёт его в ответе при `TIMA_DEV_SMS` |
| Вводит код | устройство заводится, показывается секретная фраза — **один раз** |
| Номер уже занят | предлагается вход по фразе; есть выход «Другой номер» с сохранённым номером |
| Вводит фразу | вход по прежней личности; идёт с `registration_token`, а не с кодом — код одноразовый |
| Фразы нет | «Начать заново»: новая личность, прежняя переписка не возвращается |
| Подключает второе устройство | QR на ПК, подтверждение телефоном, deep link |
| Открывает «Устройства» | список своих устройств, отключение чужого, номер сборки внизу |

Номер сборки виден **на экране входа** и **в «Устройствах»**: первый — чтобы проверить
обновление до входа, второй — чтобы ответить на «какая версия стоит», когда что-то не так.

### Переписка

| Что человек делает | Что происходит |
|---|---|
| Открывает список | переписки, отсортированные по последнему сообщению; пустые (только что созданные группы) идут первыми |
| Начинает новую по номеру | поиск по номеру; «этого номера в TIMA нет» — отдельный исход, не ошибка |
| Пишет сообщение | уходит в очередь, отметка меняется: ждёт → ушло → не ушло |
| Читает переписку | реплики с временем, отметками, состоянием; нечитаемое остаётся строкой, а не исчезает |
| Открывает группу | то же окно, но у каждой чужой реплики виден автор |

### Группы

| Что человек делает | Что происходит |
|---|---|
| Создаёт группу | название и номера приглашаемых накапливаются до создания; незарегистрированные номера показываются отдельно, группа при этом создана |
| Открывает состав | список участников с ролями; управление видно только тому, кому оно разрешено |
| Зовёт по номеру | участник добавляется, ключ группы сменяется |
| Исключает участника | участник убирается, ключ сменяется; если сменить не удалось — сказано словами, потому что до смены ключа исключённый читает новое |
| Видит недоступную историю | «сообщение недоступно» и полоса с кнопкой «Запросить ключ» — одна на экран, а не у каждой строки |
| Запрашивает ключ | просьба уходит участникам, у которых он есть; исходы различаются: «ушла к N устройствам», «ни у кого нет», «нужна секретная фраза» |

## Чего в интерфейсе нет вовсе

Не заглушки — просто не построено. Здесь для того, чтобы не искать:

- вкладки «Контакты» и «Звонки» (данные контактов готовы, экрана нет);
- переключатель окон и окна 2–7;
- поиск (`интерфейс.md §9`);
- медиа: вложения, превью, галерея;
- звонки и аудиочаты;
- реакции, ответы на сообщение, ветки.

## Раскладки

Основа для планшета и ПК есть — `Стан` из четырёх полос (`У.4`). Экраны в неё посажены
частично: на ПК приложение открывается и работает, но раскладка «список рядом с
перепиской» задействована не везде.
