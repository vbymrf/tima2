# Окно «Медиа» — заглушки

| Что стоит сейчас | Что должно быть | Чем держится |
|---|---|---|
| Вкладка «Общая» — надпись о том, что здесь будет | медиа-лента карточками и режим «слайды» | ни медиа-постов, ни ленты сервер не отдаёт |
| Переключатель «Лента / Слайды» стоит в ряду вкладок и настоящий, но меняет только надпись | два способа смотреть одно и то же | смотреть нечего. Режим сохраняется при смене вкладки — это состояние окна, а не вкладки |
| Пары «вида» ▬/▦ в «Каталоге» нет | «полоса разделов / ярлычки» справа в ряду вкладок | полосы разделов не существует |
| Вкладка «Друзья» — надпись о том, что здесь будет | медиа людей из книги | тот же социальный слой, которого нет |
| Вкладка «Каталог» — надпись о том, что здесь будет | коллекции по разделам с метками защиты | коллекций нет ни в базе, ни на сервере |
| «Лупа» ничего не открывает | подокно «Поиск» по этому окну (`§9`) | подокно не построено |
| «Шестерёнка» открывает «Устройства» | подокно «Настройки» (`§9`) | из разделов настроек существует один |
