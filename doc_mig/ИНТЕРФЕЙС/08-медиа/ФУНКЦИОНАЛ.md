# Окно «Медиа» — что работает

Макет: [`медиа.html`](../../../doc/Layout-UI-light/телефон/окна/медиа.html); описание — `интерфейс.md §5`.

**Назначение:** фото и видео в двух режимах. **Вкладки:** Общая · Друзья · Каталог.

Построена оболочка окна: шапка с именем и кнопками, ряд вкладок, переключение между
ними и память выбранной вкладки. Содержимого нет — и это не недоделка, а состояние
сервера: социального слоя на нём нет вовсе.

| Действие | Последствие |
|---|---|
| Открыть окно | вкладка та, на которой его оставили; первая — при первом входе |
| Переключить вкладку | содержимое сменилось |
| Открыть «Общая» | сказано словами, что здесь будет — медиа-лента карточками и режим «слайды»; и чем это держится сейчас — ни медиа-постов, ни ленты сервер не отдаёт |
| Открыть «Друзья» | сказано словами, что здесь будет — медиа людей из книги; и чем это держится сейчас — тот же социальный слой, которого нет |
| Открыть «Каталог» | сказано словами, что здесь будет — коллекции по разделам с метками защиты; и чем это держится сейчас — коллекций нет ни в базе, ни на сервере |
| Нажать логотип | переключение окон |
| Нажать «шестерёнка» | «Устройства» |

**Выдуманных записей в окне нет.** Показать здесь ленту можно было бы только
нарисовав её: нарисованные данные однажды уезжают в сборку и принимаются за
работающие, и этим проект уже болел.
