# Окно «Страница» — связи

| Откуда | Действие | Куда | В коде |
|---|---|---|---|
| Окно, вид владельца, любая вкладка | логотип с именем окна | Переключение окон | да |
| Окно | свайп по средней зоне | соседнее окно | да |
| Окно | вкладка | другая вкладка того же окна | да |
| Окно | «шестерёнка» | «Устройства» | да |

## Из макета, не построено

| Откуда | Действие | Куда | Чем держится |
|---|---|---|---|
| Окно, вид посетителя, любая вкладка | «назад» | **окно, из которого перешли на эту страницу** | вида посетителя нет вовсе |
| Окно | «лупа» | подокно «Поиск» | не построено |
| Содержимое вкладки | любое действие над записью | подокна «Комментарии», «Оценка», «Переходы», «Текст поста» | содержимого нет |
| Строка ленты, чата, поиска с именем или аватаром человека | нажатие | окно 5, вид посетителя | чужого профиля неоткуда взять |

## «Назад» у посетителя — возврат, а не переход в назначенное окно

**Кнопка «назад» возвращает в то окно, из которого на страницу перешли**, и другого
правила у неё нет. Пришли из социальной ленты — вернёт в окно 2, из медиа-ленты — в
окно 3, из подокна «Чат» или «Переходы» — туда же. Адрес назначения известен только в
момент нажатия, потому что он и есть предыдущее место.

В макете у этой кнопки стоят `новости.html` и `медиа.html`. **Это не выбор окна, а
свойство гиперссылки**: статичной странице нужен адрес, и взят самый частый источник
перехода. Читать эти адреса как «назад ведёт в окно 2» нельзя.

**У владельца кнопки «назад» нет ни на одной вкладке** — вместо неё стоит логотип с
именем окна, ведущий в переключение окон.
