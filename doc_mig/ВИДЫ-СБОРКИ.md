# Виды сборки Android: отладочная и быстрая

Решение — [ADR-0043](../doc/adr/0043-two-android-build-kinds.md). Почему так — беда
[2026-10-08-redmi-тормозит-и-свайп.md](БЕДЫ/2026-10-08-redmi-тормозит-и-свайп.md). Документ для
человека и для агента: когда какую, как собрать, поставить, проверить и вернуть.

## Коротко

| | Отладочная | Быстрая |
|---|---|---|
| Когда | **всегда по умолчанию**: раздача со стенда, телефоны для сценариев агента | замер скорости; слабый телефон, которому нужна скорость; показать, как будет без флага отладки |
| Собрать и поставить | `update-and-install-phone.bat` | `update-and-install-phone.bat -Fast` |
| Gradle | `:app-android:assembleDebug` | `:app-android:assembleFast` |
| APK | `client/app-android/build/outputs/apk/debug/app-android-debug.apk` | `client/app-android/build/outputs/apk/fast/app-android-fast.apk` |
| Имя версии | `2.0.N-dev-v2` | `2.0.N-dev-v2-fast` |
| Пакет, подпись, номер | `io.tima.app.v2`, `5877a0b5…`, общий | те же |
| Раздаётся стендом | да | **нет** — только по прямому указанию заказчика |
| Журнал | внутри; агент читает `run-as` | внутри; только «Настройки → Сообщить о проблеме» |

## Как собрать и поставить быструю

```bat
update-and-install-phone.bat -Fast -Serial <адрес телефона>
```

Скрипт:

1. собирает `assembleFast`;
2. печатает отпечаток подписи — обязан начинаться на `5877a0b5`;
3. ставит поверх (`install -r`, данные сохраняются);
4. проверяет, что флага `DEBUGGABLE` нет;
5. **компилирует сразу** — `cmd package compile -m speed-profile -f io.tima.app.v2` — и печатает
   «скомпилирована по профилю»;
6. запускает.

Без скрипта (агент, своим adb):

```bash
cd client && ./gradlew :app-android:assembleFast
apksigner verify --print-certs app-android/build/outputs/apk/fast/app-android-fast.apk   # 5877a0b5…
adb -s <адрес> push app-android/build/outputs/apk/fast/app-android-fast.apk /data/local/tmp/t.apk
adb -s <адрес> shell pm install -r /data/local/tmp/t.apk
adb -s <адрес> shell cmd package compile -m speed-profile -f io.tima.app.v2
```

Пакет для передачи — `doc_add/packages/TIMA-N-fast.apk`, чтобы не спутать с раздаваемым `TIMA-N.apk`.

## Как проверить, что стоит

```bash
adb -s <адрес> shell dumpsys package io.tima.app.v2 | grep -E "versionName|flags=\["
#   versionName=2.0.N-dev-v2-fast,  в flags нет DEBUGGABLE
adb -s <адрес> shell dumpsys package dexopt | grep -A2 "\[io.tima.app.v2\]"
#   status=speed-profile — скомпилирована;  status=verify — ещё нет
```

В приложении: «О приложении» — версия с `-fast`.

## Компиляция: что происходит без команды

Быстрая сразу после установки работает на компиляторе «на ходу» — уже втрое быстрее отладочной.
Полную скорость даёт компиляция по профилю: система делает её сама в фоновом обслуживании, когда
телефон **на зарядке и не используется** — раз в сутки, обычно ночью. **Каждое обновление её
сбрасывает.** Поэтому на стендовых телефонах агент компилирует сразу (шаг 5).

Отладочную сборку компилировать бесполезно: Android оставляет её в `status=verify`.

## Как вернуть отладочную

Поставить отладочную той же или большей версии — `update-and-install-phone.bat` — или дождаться
следующей раздачи: номер общий, обновление встанет поверх само. Данные сохраняются.

## Чего на быстрой не сделать

У агента нет `run-as` — это не поломка, чинить не надо:

- журнал с телефона не читается (`phone.py`, `probe_run.py`) — только отчётом «Сообщить о проблеме»;
- сценарии на телефонах не гоняются — проверки идут по журналу;
- наборы и отчёты стенда звонков не кладутся и не забираются (`push-bench-presets`, `pull-bench-reports`).

Нужно что-то из этого — поставить отладочную.

## Замер скорости — только на быстрой

Замер на отладочной говорит о флаге отладки, а не о коде. Порядок, которым мерили Redmi:

```bash
adb -s <адрес> shell dumpsys gfxinfo io.tima.app.v2 reset
# сценарий: прокрутки списка, смены окна
adb -s <адрес> shell dumpsys gfxinfo io.tima.app.v2    # кадров, дёрганых, 50/90/99%
adb -s <адрес> logcat -d | grep -E "Davey|Skipped [0-9]+ frames"   # долгие кадры
```

Скрипты замеров и свайпов — в беде; сравнивать до и после на одном телефоне и в одном состоянии
компиляции.
