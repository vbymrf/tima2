# Беды — разбор

Здесь лежат разборы бед, которые дорого стоили и могут вернуться. Не список задач и не
журнал падений: задачи живут в планах, падения — в
[ЖУРНАЛ-И-ОТЛАДКА](../ЖУРНАЛ-И-ОТЛАДКА/ПРАВИЛО.md).

## Что сюда попадает

Беда попадает сюда, если верно **хотя бы одно**:

- **она притворялась другой бедой** — то есть по симптому её причину определить нельзя;
- **вывод о причине один раз оказался неверным** — значит очевидное объяснение здесь
  ложное, и следующий пойдёт по тому же ложному следу;
- **она возвращается** — второй раз одно и то же место;
- **её нашли не там, где она живёт** — симптом в одном слое, причина в другом.

Беда, причина которой видна из сообщения об ошибке, сюда не попадает. Её чинят и забывают;
запись о ней только разбавит те, что читать обязательно.

## Что обязано быть в записи

| Раздел | Зачем |
|---|---|
| **Что было видно** | словами человека, а не терминами кода: с этого начнётся следующий, кто её встретит |
| **Чем это казалось** | ложные объяснения, которые звучали убедительно, — с пометкой, почему не они |
| **Доказательство** | стек, снимок, замер, число. **Без него записи нет** |
| **Настоящая причина** | механизм, а не место: «круг запись → запрос → запись», а не «строка 146» |
| **Как починено** | и почему именно так, а не иначе |
| **Чем проверено** | что именно перестало происходить и как это увидели |
| **Чему учит** | правило, которое из этого следует, — или честное «ничему, случай единичный» |

**Доказательство обязательно, и это главное правило папки.** На этом проекте трижды за два
дня вывод о причине, сделанный рассуждением вместо замера, оказывался неверным: «Maestro не
умеет параллельно», «таймаут драйвера обязателен», «виснет на группах без ключа». Каждый
раз объяснение было связным и каждый раз ложным. Запись без доказательства закрепляет
именно такое объяснение — и стоит дороже, чем её отсутствие.
