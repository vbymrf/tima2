# «Назад» ходит по кругу на странице сущности (2026-11-23)

Отчёт `QV7K` со стенда: realme RMX3269, сборка 275, 2026-11-23 15:08 — «зациклилась кнопка назад».

## Что было видно

Группа «gruppa»: «Управление → Сообщения» → «Написать суперсообщение» → редактор в переписке → «Назад» → снова
«Сообщения», «Управление», переписка, «Сообщения»… — выйти к каталогу не получалось.

## Чем это казалось

- **«Назад» не работает»** — нет: каждое нажатие честно закрывало одно звено.
- **«Петля в одном окне»** — нет: окна были разные, они повторялись.

## Доказательство

Журнал отчёта: `NAV открыто … что=chat звеньев=4` → `showcase 5` → `manage.messages 6` → `chat 7` → … →
`manage.messages 9` → `chat 10`. Цепочка росла кругами: «Написать» в «Сообщениях» у группы открывал переписку группы
новым звеном, шапка переписки — страницу, вкладка — «Управление», и так снова. Навигатор узнавал «то же окно» только на
верхнем и предыдущем звене (`Navigator.open`), а правило М20 ПЛАН-(МП) (2026-11-09) велело повтор не подряд класть
новым звеном.

## Настоящая причина

Две вместе: 1) правило М20 — повтор окна углублял цепочку; 2) «Сообщения» у группы уводили в переписку, чтобы
отправить сообщение уровня 0 (подписывает его отправка переписки), — круг замыкался.

## Как починено

1. `Navigator.open`: окно уже есть ниже по цепочке — возврат к нему, всё после отрезается (М20 изменён заказчиком
   2026-11-23: «нужно выходить наверх, а не входить вглубь»).
2. «Управление → Сообщения» у группы: редактор открывается в этом же окне, сообщение уходит той же очередью отправки, что
   из переписки (`SendComposed`), номер с сервера ждётся в фоне — затем суперсообщение и замена прежнего. «Назад» из
   редактора — в «Сообщения».

## Чем проверено

`NavigatorTest.открытое_ниже_по_цепочке_возвращает_к_нему_а_не_углубляет` (круг из отчёта); `NavigatorChainTest` —
под новое М20. Живьём — после установки.

## Чему учит

Правило истории «как в браузере» не годится для окон, которые ссылаются друг на друга: переписка открывает страницу,
страница — переписку. Цепочка таких окон должна сходиться к уже открытому, а не расти.
