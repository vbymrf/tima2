# Версии: что где стоит

Одно место на вопрос «а что у нас сейчас развёрнуто и что установлено». Заведено
2026-08-26, потому что ответ каждый раз собирался заново — по журналам, по SSH, по
памяти, — и каждый раз получался разный.

**Правило простое: что не записано здесь, того мы не знаем.** Не «наверное так» — не
знаем. Запись без даты и без источника хуже отсутствующей: отсутствующую идут проверять,
а такой верят.

## Что лежит

| Файл | О чём | Отслеживается git |
|---|---|---|
| [СТЕНД.md](СТЕНД.md) | сервер: развёрнутый коммит, тег, миграции, службы, настройки | да |
| [КЛИЕНТЫ.md](КЛИЕНТЫ.md) | приложения по платформам: какая версия собирается и что установлено | да |
| `ТЕЛЕФОНЫ.local.md` | тестовые телефоны и аккаунты — **секретные фразы** | **нет**, и не будет |

## Почему секреты лежат здесь же, но не едут

`*.local.md` целиком в `.gitignore` — то же правило, по которому живёт
`doc_mig/ОКРУЖЕНИЕ.local.md`. Файл лежит рядом, потому что искать его в другом месте
никто не станет, но на вторую машину он не поедет и в историю не попадёт.

Секретная фраза аккаунта — это сам аккаунт: кто её знает, тот и владелец. Ей место не в
репозитории.

## Как это заполнять

**Только измеренным.** Каждая строка обязана называть, откуда взята и когда. Три
источника, и все три спрашивают саму систему, а не человека:

```bash
# сервер: что развёрнуто на самом деле
ssh tima-stand 'git -C /opt/tima log -1 --format="%h %ad %s" --date=short'
ssh tima-stand 'docker exec tima-postgres-1 psql -U tima -d tima -tAc "SELECT count(*), max(name) FROM schema_migrations"'

# что собирается у нас
grep '^tima\.' client/gradle.properties

# что стоит на телефоне
adb -L tcp:10.0.2.2:5037 -s <устройство> shell dumpsys package io.tima.app.v2 | grep -E 'versionCode|versionName'
```

**Пробой снаружи версию сервера не определяет** — это стоило ошибки 2026-08-26. Все
маршруты отвечали одинаково и до, и после выкатки, потому что разбор на регистраторы и
переименование поведения не меняли. Спрашивать надо сам сервер.

## Что сюда добавится

Названо, чтобы не заводили рядом второе такое же место:

- **iOS** — сборки нет, модуля `app-ios` нет; таргеты в библиотеках есть. Появится —
  строка в `КЛИЕНТЫ.md`, а не новый файл;
- **сборка для ПК как артефакт** — сегодня десктоп собирается из исходников запускалкой,
  готового установщика нет и раздавать нечего;
- **вторая машина сборки** — если у неё своя подпись APK, это отдельная строка: подпись
  определяет, обновится пакет или потребует переустановки.
