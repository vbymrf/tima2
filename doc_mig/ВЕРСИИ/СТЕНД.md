## Как было: развёрнутый сервер — актуальный

Заказчик сказал «в сети живая старая версия». Проверено: **это верно про клиента и
неверно про сервер.**

```
git diff 3c491bb HEAD -- server/   →  43 файла, +4977/-3266   (2026-08-26)
git diff 3c491bb HEAD -- schema/   →  0 строк
```

После 14 августа менялись только клиент, макет, документация и `third-party` —
серверный код и схема не тронуты. Значит **клиент v2 можно писать против того, что
развёрнуто**, без риска расхождения. Это снимает главный риск использования сетевого
стенда вместо локального.

## Режим SMS: `TIMA_DEV_SMS=1` включён

Проверено запросом, а не чтением конфигурации:

```
POST https://api.<домен>/api/v1/auth/sms/request  {"phone":"+79990000042"}
→ 200 {"dev_code":"…","request_id":"85a1bf3b-…"}
```

Код возвращается прямо в ответе. **Значит блокера для регистрации тестовых аккаунтов
нет** — харнесс К4 сможет заводить их сам, без походов за логами.

Оговорка, чтобы это не забылось: с этим флагом **зарегистрироваться может любой, кто
знает домен**. Для тестового стенда с пустой базой приемлемо; в бою флага быть не
должно.
