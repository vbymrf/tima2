## Сервер: СЦ18, СЦ19, СЦ21–СЦ23 — `b8f5a99c`

Миграция **0091** (аддитивная): роль у строки команды канала (`channel_moderators.role`: admin | moderator, нынешние —
модераторы); `show_members` у групп, каналов, сообществ (по умолчанию включено); `channels.slow_mode_sec`; таблица
`entity_bans` (канал, сообщество); `channel_posts.body` — тело документом; время правки у записи канала и сообщения
сообщества.

| Что | Как сделано |
|---|---|
| Админ канала (СЦ21) | `POST /channels/{id}/moderators` принимает `role`; админа назначает владелец, модератора — владелец и админ; снимает владелец любого, админ — модератора; `GET …/moderators` отдаёт ещё `admins`. Прежний запрос без `role` — «модератор» |
| Публикация в канал | владелец, админ, модератор (было — только владелец, `not_owner`); команда видит все круги записей |
| «Основное» канала | владелец и админ (было — только владелец) |
| Подписчики канала и сообщества | `GET /{channels,communities}/{id}/subscribers`: команде — номера, владелец, команда, админы, забаненные; подписчику — только номера, если «Показывать участников» включено, иначе 403 |
| «Исключить» и «Забанить» | `DELETE …/subscribers/{userID}`, `POST`/`DELETE …/subscribers/{userID}/ban`; команда, цель — ниже рангом, владельца — никто; исключённый из команды теряет роль; журнал ролей — `remove`, `ban`, `unban` |
| Наследование в сообществе (СЦ23) | исключение снимает подписку на сообщество, подписки и роли в его каналах, участие в его группах (кроме владельца группы); бан проверяется по `community_id` элемента — подписка на канал, вход в группу (добавление, заявка, приглашение) закрыты |
| «Показывать участников» (СЦ19) | `PUT /{вид}/{id}/show-members` — владелец и админ; `POST /entities/show-members` — пачкой |
| Суперсообщение и уровень 0 (СЦ18) | ставят владелец, админ, модератор (у сообщества — владелец и админы); уровень 0 в группе — только команда (`showcase_staff`, было — любой участник) |
| Правка и удаление описания (СЦ18) | `PATCH /channels/{id}/posts/{postID}` — автор; `PATCH`, `DELETE /communities/{id}/messages/{messageID}` — правит автор, удаляют владелец и админы; удалённое суперсообщение освобождает место |
| Тело записи (СЦ22) | запись и комментарий канала принимают `body` (MessageBody, base64url); с телом текст может быть пустым; выдача ленты, описания, записи по номеру, комментариев — с `body` |
| Медленный режим комментариев (СЦ21) | `PUT /channels/{id}/slow-mode {sec}` — владелец и админ; команда не ждёт; `429 slow_mode` |

Не перенесено с группы, по устройству канала: **«Заявки»** — у канала нет закрытого входа по карточке (публичный —
подписка сразу, секретный — приглашение); **«Доступ»** — у канала поимённые разрешения стоят на записи
(`feed_level_grants`, К4), а не на человеке, как у группы.

Личные группы внутри сообщества: исключение снимает участие на сервере, но **смену ключа** (ADR-0017) сервер не
вызывает — напоминание о ротации идёт только из путей группы; исключённый остаётся с прежним ключом и без доступа к
новым сообщениям на сервере.
