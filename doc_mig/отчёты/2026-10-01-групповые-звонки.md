## 1. Сервер: ГЗ1 и ГЗ2 — коммит `67e964ed`

Сделано поверх того, что уже было: групповой звонок на сервере существовал с миграции 0023
(`POST /calls/group`, приглашённые, вход `POST /calls/{id}/join`, учёт входа и выхода по вебхуку
LiveKit) — без сроков, прав, команд и вызова через ленту звонков. Старая ручка не тронута.

| Что | Как |
|---|---|
| Миграция `0058_group_call_rooms.sql` | аддитивная: `groups.call_ttl_until`, `calls.paused_at`, `calls.ring`, `call_participants.invited` и `removed_at`, индексы |
| Временная группа (решение 1) | `POST /groups` с `call_temp: true` — только личная; срок `CALL_GROUP_TTL` (12 ч); у группы в ответах поле `call_ttl_until`, у обычной его нет |
| Срок двигается звонком | начало и конец звонка во временной группе отодвигают срок; у обычной группы срока нет и появиться не может (условие в запросе) |
| Уборщик | вышедшая временная группа без идущего звонка удаляется: переписка и ключи насовсем, членства закрыты, участникам — событие `group.deleted` в журнал устройства |
| Звонок в группе | `POST /groups/{id}/call {ring, video, invited}`; идёт уже — ответ входом в тот же (одна группа — один звонок) |
| Кто начинает (решение 14) | роль модератор и выше; модераторов нет — владелец; участнику — `403 group_call_forbidden` |
| Кого звать (решения 15, 16) | `invited` — только из участников группы; пусто — вся группа (временная) |
| «Звонить» (решение 3, 12) | отмеченным — `ringing` в ленте звонков, как у личного; кто не вошёл за срок вызова — `missed`; без «Звонить» — ни одного вызова |
| Вход (решения 2, 4) | любой участник группы, пока в комнате меньше 25 (`409 call_full`); удалённый — `403 removed_from_call` |
| Состояние для полосы «Идёт звонок» | `GET /groups/{id}/call`: звонок, создатель, пауза, участники (отмечен, вошёл, удалён), правила, `can_start` |
| Команды создателя (решения 5, 6, 17) | `POST /calls/{id}/control`: `mute_mic`, `mute_video` (через LiveKit, включает обратно сам участник), `remove` (из звонка, не из группы), `pause` и `resume` (данные комнаты, видят все), `stop`; не создателю — `403 not_creator` |
| Выход | `/end` в групповом — уход одного; отклонивший вызов получает `declined` на всех своих устройствах, пропущенного у него не будет |
| Правила (решение 4) | `CALL_GROUP_MAX` 25, `CALL_GROUP_HD_UPTO`/`HEIGHT` 4/720, `CALL_GROUP_SD_UPTO`/`HEIGHT` 8/480, больше — только голос; отдаются в двери звонка полем `rules` |
