## Правила

1. **Имя файла — дата и тема:** `2026-08-20-документация-и-корень.md`. Дата
   впереди, потому что сортировка по имени должна давать хронологию.
2. **«Проверено» относится к коммиту, никогда к ветке.** Отчёт без хеша — отчёт ни
   о чём. Правило то же, что в [ПРАВИЛА-РАБОТЫ.md](../ПРАВИЛА-РАБОТЫ.md), и здесь
   оно действует буквально.
3. **Что не проверено — так и написать.** Отчёт, в котором не сказано «не
   собиралось», «прогнано только на десктопе», «глазами не смотрел», вреднее
   отсутствия отчёта: на него будут опираться.
4. **Отчёт не превращается в документацию.** Если из отчёта родилось описание того,
   как система работает, — его место в `doc/`, и с указанием источника. Здесь
   остаётся только событие: сделали то-то, проверили тем-то.
5. **Записи не переписываются задним числом.** Ошиблись — дописали строку с
   поправкой. Иначе журнал перестаёт быть журналом и становится ещё одним
   документом, которому нельзя верить.
