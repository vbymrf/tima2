## Развилки и решения по ходу

- **Групповые звонки оставлены на прежней дороге** (журнал устройства, `call.incoming` /
  `call.state`, `call.poke {call_id}`). В план они не входят, а их переделка удвоила бы срез.
- **Найдено по ходу: вебхук LiveKit объявлял личный звонок отвеченным, когда в комнату
  входил сам звонящий** — а он входит сразу. С лентой это дало бы звонящему ложное
  «ответили»; починено тем же срезом.
- **Звук играет приложение, каналы беззвучные (ВЗ3, ВЗ5).** План предполагал для звука
  сообщения пересоздание канала на каждую смену выбора. Сделано иначе, и довод сильнее:
  мелодия звонка обязана идти по кругу (звук канала — один раз), свой файл из папки
  приложения системный звук не прочитает без FileProvider, а пересоздание канала на
  каждую смену стирало бы настройки канала, сделанные человеком. Поэтому один переезд на
  беззвучные каналы `.2`, и звучит приложение само — по выбору из настроек.
- **`taken` как отдельное слово исчезло**: «ответили на другом устройстве» — это `answered`
  с `here = false` в ответе ленты, который составлен для спрашивающего устройства.
