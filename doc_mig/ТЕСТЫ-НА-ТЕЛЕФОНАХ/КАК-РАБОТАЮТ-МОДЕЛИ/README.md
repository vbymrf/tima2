# Как работают модели прогона

Заведено 2026-09-15. Здесь — **устройство инструментов**, а не выбор между ними.

Разница с соседними файлами:

| Где | О чём |
|---|---|
| [../МОДЕЛИ.md](../МОДЕЛИ.md) | **какую брать**: сравнение, замеры, решение |
| **эта папка** | **как она себя ведёт**: что показывает, когда останавливается, что кладёт в отчёт |
| [../ЯЗЫК.md](../ЯЗЫК.md) и прочие | **что прогонять**: сами тесты |

**Зачем отдельно.** Сравнение читают один раз, когда выбирают. Устройство инструмента
читают каждый раз, когда прогон упал и надо понять, что это значит. Смешав их, получаем
документ, который для второго случая слишком длинный, а для первого слишком подробный.

**Пишется по наблюдениям, а не по документации инструмента.** Каждое утверждение здесь
подтверждено прогоном на наших телефонах, и там, где подтверждения нет, так и сказано.
