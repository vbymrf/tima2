## Адреса

| Что | Адрес |
|---|---|
| Домен | `пацак.рф` → punycode `xn--80aa4ar0b.xn--p1ai` |
| **API** | `https://api.xn--80aa4ar0b.xn--p1ai` — **на поддомене `api.`** |
| Корневой домен | отдаёт 404: API там не живёт |
| По IP | TLS **не встаёт** — Caddy отдаёт сертификат по имени, для адреса его нет |

> **Домен внутренационализированный (IDN).** В TLS и в заголовке `Host` едет
> punycode. Клиент, которому `serverUrl` вводят руками, обязан переводить
> кириллическое имя в punycode сам — иначе человек введёт «пацак.рф», а соединение не
> встанет. Пункт для К3 (`core-network`).

## Главное: развёрнутый сервер — актуальный

Заказчик сказал «в сети живая старая версия». Проверено: **это верно про клиента и
неверно про сервер.**

```
git diff 3c491bb HEAD -- server/   →  0 строк
git diff 3c491bb HEAD -- schema/   →  0 строк
```

После 14 августа менялись только клиент, макет, документация и `third-party` —
серверный код и схема не тронуты. Значит **клиент v2 можно писать против того, что
развёрнуто**, без риска расхождения. Это снимает главный риск использования сетевого
стенда вместо локального.

## Режим SMS: `TIMA_DEV_SMS=1` включён

Проверено запросом, а не чтением конфигурации:

```
POST https://api.<домен>/api/v1/auth/sms/request  {"phone":"+79990000042"}
→ 200 {"dev_code":"…","request_id":"85a1bf3b-…"}
```

Код возвращается прямо в ответе. **Значит блокера для регистрации тестовых аккаунтов
нет** — харнесс К4 сможет заводить их сам, без походов за логами.

Оговорка, чтобы это не забылось: с этим флагом **зарегистрироваться может любой, кто
знает домен**. Для тестового стенда с пустой базой приемлемо; в бою флага быть не
должно.

## Как это проверялось

```bash
# состояние и коммит
ssh <стенд> 'docker ps; git -C /opt/tima log -1 --format="%h %ad %s" --date=short'

# уровень миграций (значения POSTGRES_USER/DB берутся из .env, пароли не нужны)
ssh <стенд> 'docker exec tima-postgres-1 psql -U <user> -d <db> \
    -tAc "select count(*), max(name) from schema_migrations"'

# снаружи, без SSH
curl https://api.<домен>/healthz                  # {"status":"ok"}
curl https://api.<домен>/api/v1/app/version       # version_code 24
```

## Что здесь неполно

- **Тега `deploy/` нет** — неподвижной записи о выкатке не существует, только эта
  таблица. Поставить тег на `3c491bb` стоит одной командой и закрывает пробел.
- **Кем развёрнуто — неизвестно.**
- Каталог `/opt/tima` — полный чекаут репозитория, включая `client/`, который в
  `stand` уже удалён. При следующей выкатке это разойдётся ещё сильнее.
