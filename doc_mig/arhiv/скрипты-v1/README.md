# Пусковые скрипты v1

Перенесены сюда 2026-08-20 вместе с удалением `client/` (этап К0.4). **Все 15
неработоспособны**: каждый прямо или через `.bat`-обёртку зовёт сборку из
`client/`, которого больше нет.

Оставлены не для запуска, а как **описание того, как приложение собиралось,
ставилось и отлаживалось** — при написании пусковых скриптов v2 (этап К1) отсюда
берётся последовательность действий, а не код.

| Скрипт | Что делал |
|---|---|
| `update-app.ps1` | сборка и обновление, основной путь |
| `update-and-install-phone.ps1` · `ОБНОВИТЬ-ТЕЛЕФОН.bat` | сборка APK и установка на телефон через adb |
| `update-and-run-desktop.ps1` · `ОБНОВИТЬ-И-ЗАПУСТИТЬ-ПК.bat` | сборка и запуск десктопной версии |
| `start-tima.ps1` · `ЗАПУСК-TIMA.bat` | запуск стека |
| `start-android.ps1` · `ЗАПУСК-ANDROID.bat` | запуск на Android |
| `run-app.ps1` · `ЗАПУСК-ПРИЛОЖЕНИЯ.bat` · `ПРИЛОЖЕНИЕ-ПК.bat` | запуск приложения |
| `debug-tima.ps1` · `ОТЛАДКА-TIMA.bat` | отладочный запуск |
| `ОБНОВИТЬ-ПРИЛОЖЕНИЕ.bat` | обёртка обновления |

Живая v1 доступна двумя путями, и оба не требуют этих скриптов:

- собранные `TIMA-*.apk` в корне репозитория (вне гита) — ставятся на телефон как есть;
- тег `ref/client-v1` — исходники: `git checkout ref/client-v1 -- client/`.

> **Правило репозитория для `.ps1` с кириллицей: сохранять с BOM.** Windows
> PowerShell 5.1 читает файлы без BOM как ANSI, кириллица разваливается, и разбор
> падает на первом же апострофе внутри строки. При написании скриптов v2 — то же.
