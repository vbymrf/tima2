# Допустимые хосты проекта TIMA.
#
# Единственный список того, куда код, сборка и выкатка проекта имеют право обращаться.
# Читается сканером doc_vnedren/check-external-access.ps1. Всё, чего здесь нет, сканер
# считает внедрением: в коде и конфигурации — нарушение, в документации — к сведению.
#
# Формат: `host | зачем`. `*.suffix` — все поддомены suffix (сам suffix — отдельной строкой).
# Имена без точки (backend, minio, redis…) и адреса петли сканер считает локальными сам.
#
# Правило добавления: строка появляется здесь ТОЛЬКО с решением заказчика и с причиной.
# Хост без причины — не запись, а дыра.
