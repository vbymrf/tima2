# Правила: телефоны и приложение TIMA

Все встречены 2026-09-29 на Samsung SM-A405FM, Redmi 23129RN51X, realme RMX3269,
Honor KSA-LX9 (сборка 87).

## Трубка в шапке переписки — голосовой звонок
- code: PH-1
- kind: preventive
- symptom: звонок идёт, а видео нет; в журнале «звонок начат … видео=false».
- check: журнал звонящего, строка «звонок начат».
- cause: «📞» в шапке переписки (`chat:call`) — голосовой; видеозвонок в переписке — «•••» → «Видеозвонок».
- fix: видеозвонок — «Контакты» → строка собеседника → «📹» (`book:video-call`).
- verify: «звонок начат … видео=true».

## «Завершить» — значок без подписи
- code: PH-2
- kind: preventive
- symptom: скрипт не кладёт трубку, звонок идёт дольше заданного.
- check: дерево окна звонка — кнопки «Завершить» текстом нет.
- cause: кнопка — значок «📞» внизу окна звонка.
- fix: класть трубку `phone.hang_up()` или `flows/call-hangup.yaml` — они ищут «📞» в окне звонка (PH-10).
- verify: «звонок закончен» / «звонок кончился» у обоих.

## «Назад» из окна стенда закрывает приложение
- code: PH-3
- kind: preventive
- symptom: собеседник звонит, сервер отвечает «вызов доставлен — у собеседника звонит», а на телефоне звонка нет; позже приходят все пропущенные разом и сразу закрываются.
- check: `dumpsys window | grep mCurrentFocus` — не TIMA; в журнале телефона нет строк после ухода.
- cause: окно стенда — последнее в стеке; «Назад» закрывает активность. Закрытое приложение звонков не принимает (у Redmi его затем выгружает система).
- fix: после «Назад» сразу `am start -n io.tima.app.v2/io.tima.app.MainActivity`.
- verify: `tab:Chats` на экране.

## Honor во время видео не отдаёт дерево экрана
- code: PH-4
- kind: preventive
- symptom: `uiautomator dump` → «ERROR: could not get idle state».
- check: идёт видеозвонок на Honor KSA-LX9.
- cause: экран с видео не «успокаивается», дамп его не дожидается.
- fix: в паре с Honor нажатия во время видео делает другой телефон: Honor звонит, второй принимает и кладёт трубку. Проверки — по журналу Honor, не по экрану.
- verify: элемент «Выход» достигнут без чтения экрана Honor.

## Пункт «Видеозвонок» в меню «•••» без координат
- code: PH-5
- kind: curative
- symptom: меню «Настройка переписки» открыто, нажатие по «Видеозвонок» не срабатывает, меню остаётся.
- check: в дереве у узла «Видеозвонок» рамка (0,0,0,0).
- cause: нижний лист отдаёт пункт без координат (находка приложения, не разобрана).
- fix: видеозвонок — через «Контакты» (PH-1). Узел с нулевой рамкой не нажимать.
- verify: «звонок начат … видео=true».

## Один владелец экрана на телефон
- code: PH-6
- kind: preventive
- symptom: `uiautomator dump` падает: «UiAutomationService … already registered»; или Maestro не может подключиться.
- check: `phone.maestro_drivers(dev)` — есть процесс `dev.mobile.maestro` (порт в строке запуска).
- cause: доступ к дереву экрана у Android один; держит его драйвер Maestro или дамп adb.
- fix: свой драйвер — остановить (`phone.stop_drivers`). Чужой (запущен не этим прогоном) — сказать заказчику и остановить с его разрешения. 2026-09-29 чужие драйверы висели на Redmi и realme с 16:59 — с другой машины.
- verify: дамп снимается.

## Не набирать, пока не кончился прошлый звонок
- code: PH-7
- kind: preventive
- symptom: «Собеседник занят другим звонком»; у принимающего «второй входящий во время звонка — не показан»; первый звонок висит.
- check: `phone.in_call(dev)` у обоих.
- cause: скрипт счёл звонок несостоявшимся и набрал снова, а первый шёл.
- fix: перед «Входом» — сброс, если `in_call` у кого-то из пары.
- verify: `in_call` ложно у обоих.

## Приложение на передний план — am start
- code: PH-8
- kind: preventive
- symptom: —
- check: —
- cause: `adb shell monkey` для TIMA запрещён в `adaptive-ops-runner`.
- fix: `am start -n io.tima.app.v2/io.tima.app.MainActivity` (`phone.to_front`).
- verify: фокус — `io.tima.app.v2/io.tima.app.MainActivity`.

## Драйвер Maestro остаётся работать после прогона
- code: PH-9
- kind: preventive
- symptom: после сценария Maestro дамп adb падает (PH-6).
- check: `phone.maestro_drivers(dev)` сразу после `run.sh`.
- cause: `run.sh` запускает с `--no-reinstall-driver`; драйвер не закрывается по концу сценария — на всех четырёх телефонах, 8 из 8 прогонов.
- fix: после каждого элемента Maestro — `phone.stop_drivers(dev)` (так делает `scenario.py`).
- verify: список драйверов пуст.

## «📞» есть и в окне звонка, и в «Контактах»
- code: PH-10
- kind: preventive
- symptom: звонок ушёл чужому контакту; в журнале «звонок начат кому=<не тот>». 2026-09-29 Samsung позвонил голосом аккаунту `880624bb` («Брат Игорь»), 45 с без ответа.
- check: журнал звонящего, «кому=»; сверка с `--peer-id`.
- cause: нажатие «📞» не глядя на экран — в «Контактах» это «позвонить» в какой-то строке.
- fix: класть трубку только в окне звонка — его узнают по «🎤» (`phone.call_screen`); звонить — кнопкой той же строки, чья рамка накрывает имя собеседника; `--peer-id` проверяет адресата.
- verify: «кому=» совпадает с собеседником.

## Имя набора в окне стенда стоит дважды
- code: PH-11
- kind: preventive
- symptom: выбор набора не срабатывает, открывается клавиатура.
- check: снимок — фокус в поле названия набора.
- cause: имя выбранного набора есть в поле «Наборы» (выше «Прогон N из M») и на плашке (ниже).
- fix: adb — последнее совпадение; Maestro — `below: 'Прогон \d+ из \d+'`.
- verify: «Прогон N из M» с ожидаемым N.

## Список окон длиннее экрана
- code: PH-12
- kind: preventive
- symptom: «нет «Стенд звонков» в переключателе».
- check: на Redmi (720×1650, особенно боком) последний видимый пункт — «Личная страница».
- cause: пункты ниже края.
- fix: прокрутить список окон до «Стенд звонков» (adb `scroll_to`, Maestro `scrollUntilVisible`).
- verify: окно стенда открыто.

## Размер экрана — с учётом поворота
- code: PH-13
- kind: preventive
- symptom: прокрутка не двигает список; жесты мимо.
- check: `settings get system accelerometer_rotation` = 1, снимок горизонтальный.
- cause: `wm size` отдаёт размер без поворота; Redmi лежал боком с автоповоротом.
- fix: размер — по рамке корня дерева (`phone.size`). Поворот в настройках не менять без разрешения; попросить заказчика поставить телефон вертикально.
- verify: прокрутка двигает список.

## Регулярка в YAML Maestro — в одинарных кавычках
- code: PH-14
- kind: preventive
- symptom: «Parsing Failed at …yaml:<строка>».
- check: в строке `"\d"` в двойных кавычках.
- cause: в двойных кавычках YAML `\d` — недопустимая escape-последовательность.
- fix: `'Прогон \d+ из \d+'`.
- verify: сценарий разбирается.

## Переменные для сценариев Maestro — через MAESTRO_<ИМЯ>
- code: PH-15
- kind: preventive
- symptom: —
- check: в `commands.json` первый `defineVariablesCommand` содержит `MAESTRO_<ИМЯ>`.
- cause: `run.sh` не передаёт `-e`; Maestro сам подхватывает переменные окружения с префиксом `MAESTRO_` (проверено 2026-09-29, 2.10.0).
- fix: `MAESTRO_PRESET=… sh maestro/run.sh …`, в сценарии — `${PRESET}` с умолчанием в `env:`.
- verify: шаг с `${ИМЯ}` получил значение.

## Подготовка run.sh нажимает HOME
- code: PH-16
- kind: preventive
- symptom: сценарий Maestro начинается не в приложении.
- check: строка подготовки «готов: … launcher».
- cause: `wake-phone.sh` кончается `KEYCODE_HOME`.
- fix: каждый сценарий начинается с `launchApp: {stopApp: false}` — без `stopApp: false` Maestro остановит приложение и оборвёт звонок; «Принять» — без `launchApp`, входящий и так на экране.
- verify: первый шаг после `launchApp` находит элемент приложения.

## Журнал приложения перестаёт писаться
- code: PH-17
- kind: curative
- symptom: хвост `files/logs/<дата>.txt` не растёт при действиях на экране; звонок кончился, а строк «закончен/кончился» нет. 2026-09-29 20:33:19 UTC — Honor и realme разом, через 6 с после соединения; звонок кончился в 20:33:22 без строки.
- check: `tail -1` журнала дважды с промежутком и действием на экране; `dumpsys media.camera` — камера отпущена.
- cause: не установлена — находка приложения.
- fix: серию остановить, заказчику — сообщить. Перезапуск приложения (`am force-stop` + `am start`) — только с разрешения.
- verify: после действия в журнале новая строка.

## «Соединён» появляется не сразу
- code: PH-18
- kind: preventive
- symptom: «Вход» не достигнут, хотя звонок соединился через секунды.
- check: время строки «стадия звонка стала=Connected» против времени проверки.
- cause: проверка шла через 3 с после «Принять».
- fix: ждать строку до 20 с, опрашивая журнал.
- verify: «Connected» найдено у обоих.
